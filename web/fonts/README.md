# 앱 안 글꼴

설정 › 화면 › 글꼴에서 고르는 글꼴 가운데 인터넷 없이도 보이게 앱에 넣은 것(core/font.js).

- `pretendard/` — 프리텐다드 1.3.9 가변 글꼴, 쓰는 글자만 받는 나눔 파일(dynamic subset). SIL Open Font License 1.1(`pretendard/LICENSE.txt`). https://github.com/orioncactus/pretendard
- `suit/` — SUIT 2.0.5 가변 글꼴. SIL Open Font License 1.1(`suit/LICENSE.txt`). https://github.com/sun-typeface/SUIT

본고딕·나눔고딕·고운돋움·고운바탕은 구글 글꼴에서 받고, 맑은 고딕은 윈도우에 들어 있는 글꼴을 써요.
