# 쌤비서

선생님의 평가·계획·학급 업무를 왼쪽 세로 메뉴 하나에 모은 교사용 AI 업무 앱입니다. AI가 초안을 쓰고, 선생님은 확인하고 고치기만 하면 됩니다.

- 2026 한국형-AI 기반 교사개발자 연수 예선 출품작 (3기-4조)
- 만든이: 한국형-AI 기반 교사개발자 연수 3기 4조

## 써 보기

- **웹판(설치 없이)**: https://doguri25.github.io/ssam-assistant/
- **Windows 앱**: [릴리즈](https://github.com/doguri25/ssam-assistant/releases)에서 `ssam-<버전>-setup.exe`(설치) 또는 `ssam-<버전>-portable.exe`(설치 없이 실행). 앱이 새 버전을 스스로 확인해요.
- AI는 설정 › AI에서 Claude·Gemini·GPT·업스테이지(Solar) 중 하나의 키를 넣고 [연결 확인]을 눌러요.
  - **업무별 AI·검토 AI**: 키를 여러 회사에 넣었으면 채점·평어(행특·창체)·계획 초안·피드백과 알림마다 쓰는 AI를 메뉴 위쪽 「AI 줄」의 [바꾸기]에서 따로 정해요. 「검토 AI로 한 번 더 보기」를 켜면 필요한 곳만(확신 없는 칸·수준 경계 학생·쓴 문장·초안) 다른 AI가 다시 보고, 의견이 다르면 노랗게 표시해 선생님이 골라요. 처음엔 꺼져 있고, 켜면 AI 사용량이 대략 1.2~1.5배예요.
  - 진도표·시간표 가져오기, 진도·시수 계산, 체크, 한글 파일 만들기처럼 AI 없이 되는 일도 많아요.
  - 문서는 한글(.hwpx)·워드(.docx)·PDF(인쇄 창의 「PDF로 저장」) 가운데 골라 내보내요. 내려받기 단추 옆 [▾]에서 고르면 그 형식을 기억해요.

## 메뉴마다 되는 일

| 메뉴 | 되는 일 |
|---|---|
| **오늘(첫 화면)** | 앱을 켜면 「오늘」이 먼저 나와요: 오늘 날짜와 「오늘 챙길 일 n가지」, 사용 중인 AI, 「무엇이든 여기에 놓으세요」(파일을 놓거나 [파일 고르기] → 떠 있는 버튼과 같이 알아보고 그 메뉴로), 카드 3개 — **공문 기한**(지남·오늘·D-n), **오늘 수업**(교시마다 교과·차시·상태, 지금·다음 교시 표시), **교과캠프 출석**(오늘 캠프 수업이 있으면 학생마다 큰 버튼·[모두 출석]) — 와 **이어서 하기**(행사·학사일정·덜 끝난 평가·품의 초안·다면평가 입력 필요). 처음 쓰면 시작 안내 3단계가 보여요. 휴대폰에서는 아래 탭 5칸(오늘·평가·학급·품의·더보기 — 계획·연수·기타·설정은 더보기 안)과 한 줄로 넘기는 탭으로 바뀌어요 |
| **떠 있는 버튼** | 아무 파일이나 넣으면(Windows 앱은 바탕화면 위 「쌤」 버튼에 끌어 놓기, 웹판은 오른쪽 아래 버튼) AI 없이 무엇인지 알아보고 확인 카드 뒤 그 메뉴에서 해 줘요: 단원평가 답안(정답·이원 분류표)·빈 문제지 → 새 단원평가, 수업 활동지 → 새 활동지, 학생 문제지 스캔 → 고른 단원평가·활동지에서 채점, 교과 평가계획 → 교과 평어, 작년 학급운영·업무·행사 계획 → 새 계획 초안(모자란 값만 입력 창), 연수·회의·행사 안내 공문 → 기타 › 쪽지 작성, 지침·공문 → 고른 계획에, 견적서 → 새 품의 초안까지, 진도표·시간표·학급 명단·설문 CSV → 그 메뉴로 |
| **파일 칸 끌어 놓기** | 파일을 넣는 단추가 있는 카드(기초학력 캠프 계획 파일·문서 양식, 다면평가 기준 양식·근거자료, 가정통신문·인수인계서 양식, 단원평가 답안·문제지, 연간계획·학급운영계획·행사계획 자료, 시간표·진도표, 학급 명단, 백업 불러오기)에 파일을 끌어다 놓으면 그 단추로 고른 것처럼 들어가요. 끌고 오면 받을 카드에 점선과 「놓으면 「양식 넣기」」가 보이고, 카드에 단추가 여럿이면 그 단추 줄만 받아요. 맞지 않는 파일은 「이 칸에는 한글·PDF·사진 파일을 넣어 주세요」처럼 알리고, 읽는 중이면 넣지 않아요. |
| **「쌤」 버튼 채팅(AI 비서)** | 오른쪽 아래 손그림 「쌤」 버튼(또는 머리 줄 말풍선 단추, Windows 앱은 바탕화면 「쌤」 버튼)을 누르면 채팅 창이 열려요. 「알코올램프 10개 5,000원 품의」, 「연수 안내 쪽지 …」, 「가정통신문 베트남어로」, 「주간학습안내」, 「인수인계서」처럼 분명한 지시는 AI 없이 그 메뉴로 가서 바로 시작해요(품의 초안·쪽지·가정통신문·공문 처리·결과 보고 쓰기까지, 저장·결재·상신은 선생님이). 「단원평가 결과지 어떻게 뽑아?」, 「AI 키 없이 써도 돼?」, 「품의 사유는 어떻게 써?」처럼 묻거나 애매한 글은 AI 비서가 쌤비서 안내와 지금 화면·오늘 할 일을 보고 대화하듯 답하고 그 화면으로 가는 버튼을 붙여요(묻기만 한 글에는 저절로 일을 시작하지 않고, 쌤비서 기능이 아닌 일반 안내는 그렇다고 밝혀요). 답을 쓰는 동안 [멈추기], AI가 없거나 실패하면 안내에서 찾아 답해요. 학생·교직원 이름(「김다빈이」, 「민준이가」, 「지호가」 등)·전화번호·명단 줄은 되도록 가려서 AI로 보내고(이름 대신 번호로 써 주세요) 기록에도 가린 글만 최근 30개 남아요. 파일은 버튼이나 채팅 창에 끌어 놓거나 📎로 넣어요 |
| **다른 메뉴로 가도 이어지는 일** | 채점·평어·행특·계획 초안·품의·쪽지·가정통신문·번역·공문 처리 같은 AI 일은 다른 메뉴로 가도 뒤에서 이어지고, 결과는 시작한 기록에 들어가요. 돌아오면 「읽는 중」·진행 표시가 그대로 보이고, 다른 메뉴에서 AI가 일하는 중이면 왼쪽 세로 메뉴 버튼에 작은 점이 떠요. 메뉴로 돌아오면 마지막에 쓰던 탭이 열려요(앱을 다시 켜도 — 앱은 「오늘」부터 열려요) |
| **아침 브리핑** | 채팅 창을 열면 맨 위에 「오늘 할 일」을 AI 없이 모아 보여 줘요([오늘 화면 열기]로 「오늘」 화면도): 공문 제출 기한(지남·D-7), 7일 안 학사일정, 14일 안인데 확정 안 한 행사계획, 덜 끝난 단원평가·활동지 채점·피드백, 진행 중인 평가지 채점, 금요일엔 다음 주 주간학습안내. 줄을 누르면 그 화면으로 가요 |
| **한 줄 관찰 메모** | 채팅에 「3번 토론에서 근거 들어 반론 잘함」(「3·5번 …」「3~5번 …」도)처럼 쓰면 평가 › 행동특성의 그 번호 메모 끝에 「[11. 6.] …」로 쌓여 학기말 행특의 근거가 돼요. 이름처럼 보이는 말은 ○○○로 가리고, [되돌리기]·「3번 메모 보기」가 있어요 |
| **평가** | 교과 평어 · 창의적 체험활동 · 행동특성 및 종합의견 · 평가지 채점(스캔한 평가지·학습지를 AI가 읽고 채점, 걷은 순서가 섞여도 적힌 번호로 학생을 맞춤), 나이스 입력 돕기. 「평어 만들기 1.8.0」에서 출발 |
| **평가 › 단원평가** | 1단계에서 [학생 문제지 넣기(스캔한 것)]로 학생이 푼 시험지 스캔을, [답안 넣기]로 정답(문항 이원 분류표·이원 목적 분류표·정답을 한 줄로 늘어놓은 정답·해설지, 문제지와 정답이 한 파일인 것도)을 넣어요(다른 단추에 넣어도 알아보고 맞는 곳에, 알기 어려운 사진 1~2장은 답안인지 학생 문제지인지 물어봐요, 빈 시험지는 「빈 문제지도 있으면 (선택)」에). 답안은 AI 없이 읽고, 반 전체 학생 문제지를 문항마다 채점(AI는 답을 읽고 앱이 정답과 맞춤, 서술형은 부분 점수, 모아찍기·양면 스캔은 쪽을 나누고 돌려서, 걷은 순서가 섞여도 첫 쪽에 쓴 번호로 학생을 맞춰서) → 노란 칸만 확인 → 학생 결과지(틀린 문항·교과서 쪽·잘한 점·격려)와 번호별 글 → 성적 일람표·학생별 누적·반 약한 부분·교과 평어 초안 |
| **단원평가 결과지 맞춤 복습 문제** | 4단계 피드백의 [복습 문제 만들기]를 누르면 AI가 틀린 학생이 있는 문항마다 같은 개념의 비슷한 문제(고르기 ①~④·단답·서술형)와 정답·짧은 풀이를 한 번에 만들어요(문항 번호·평가 내용·영역·유형·정답·교과서 쪽만 보내요). 학생마다 틀린 문항을 배점 큰 순으로, 결과지 그 학생 칸에 **남는 자리만큼 최대 3개** 「다시 풀어 보기」로 넣고 칸 맨 아래에 작은 글씨로 정답을 적어요(「번호별로 한 장씩」이면 더 많이 들어가요). 문제는 고칠 수 있고 인쇄·한글·워드·PDF·복사 모두 같아요 |
| **AI 채점 정확도** | 단원평가·활동지에서 AI가 처음 매긴 값을 칸마다 기억해 선생님이 확인·수정한 결과와 견줘 「AI가 맞힌 칸 97% (객관식 99% · 단답 96% · 서술형 88%) · 선생님이 고친 칸 7개」로 보여 줘요(채점을 마치기 전엔 「확인 중」). 목록 위에는 올해 평균이 나와요 |
| **평가 › 활동지** | 수업 중·수업 후 활동지(정답이 없거나 예시 답안·그림·주관식)를 넣으면 AI가 문항마다 ○·△ 기준을 먼저 만들고 선생님이 확인 → 반 전체 스캔을 학생마다 ○·△·×·안 함(그림은 표현까지)·잘한 점·더 해 볼 점·수준(잘함·보통·노력)으로 채점 → 노란 칸만 확인 → 반 표·피드백 쪽지(번호만), 학생별 모아 보기(교과·학기). 「교과 평어에 참고하기」를 켜면 평가지 채점에서 그 평가 영역 평어를 쓸 때 체크해서 참고 |
| **채점 AI 아끼기** | 평가지·단원평가·활동지 채점에서 학생마다 같은 정답·기준(평가지 채점의 기준 그림 포함)은 앞에 두어 AI 회사가 캐시하게 해 값이 줄고 빨라져요. 단원평가·활동지는 3~4명씩 함께 채점하고, AI 한도에 걸리면 잠깐 쉬었다가 이어 가요. 채점이 끝나면 「AI 사용량」 한 줄(캐시로 아낀 비율)을 보여 줘요 |
| **한꺼번에 넣기** | 단원평가·평가지 채점·활동지에서 정답·교사용과 문제지·학생 답안을 따로 넣지 않고 한 번에 넣어도 알아서 나눠요(한 파일 안의 학생용·교사용·(예시)·[정답], 스캔 묶음 앞뒤의 정답·교사용 쪽). 나눈 결과를 카드로 보여 주고 확인한 뒤 넣어요 |
| **계획 › 연간계획** | 작년 계획서·결과·올해 지침 → 작년 평가 → 지침 점검(빠진 것 넣기) → 초안(작년과 겹치는 정도) → 월별 일정(공휴일·방학·다른 일정과 겹침, 추천 날짜) → 한글 파일·확정(학사일정에 넣기) |
| **계획 › 행사계획** | 행사 정보·참고 자료(상위 계획·교육청 공문) → 구성안 2~3개 → 계획서·안전 점검표·가정통신문 → 확정·만족도 설문(구글 폼 문항, QR, 응답 CSV로 결과 보고서·내년 개선 메모) |
| **계획 › 학급운영계획** | 작년 학급운영계획(학급 교육과정 운영 계획)의 목차 그대로 올해 초안 → 올해 지침 점검(반영됨·빠짐, [넣기]) → 작년과 겹치는 정도 → 진도표·평가계획 첨부를 읽어 교과별 시수표·평가 표(진도표는 학급 메뉴에도) → 한글 파일·확정. 작년 파일의 담임 명단·전화번호 줄은 빼고 읽어요 |
| **계획 › 결과 보고** | 계획서·관련 공문·작년 결과 보고서(한글·PDF·워드)와 「한 일」 메모, 행사 사진(12장까지)을 넣고 [결과 보고 쓰기]를 누르면 AI가 사진도 보고 **결과 보고 공문**(관련 → 「위 호와 관련하여 … 결과를 다음과 같이 보고합니다.」 → 가. 일시·나. 장소·다. 대상·라. 주요 내용 → 「붙임  … 결과 보고서 1부.  끝.」)과 **결과 보고서**(개요 표·작년 보고서의 소제목 차례·사진 자료 2장씩과 설명)를 써요. 한글·워드·PDF로 내려받기. 칸을 고치면 공문도 다시 맞춰요. 원본 파일과 사진은 저장하지 않아요. 행사계획의 [결과 보고 공문·보고서 쓰기]로도 와요. 가정통신문에서 넣어 둔 학교 양식(.hwpx)을 고르면 그 양식에 개요 표·사진 표까지 넣어 내려받아요 |
| **학급 › 진도표·시수** | 학교의 「교과-창체 연간지도계획」·「학년별 기초시간표」 한글 파일을 AI 없이 읽어 교과 진도표와 우리 반 시간표를 넣고, 교과별 계획·실시·남은 시수와 진도 차이(+1, −2)를 보여 줘요 |

## 시연 순서 (샘플 파일: [`samples/`](samples/), 모두 지어낸 예시)

0. **떠 있는 버튼**: `samples/`의 아무 파일(예: `단원평가-정답지-예시.hwpx`, `학급운영계획-작년-예시.hwpx`, `진도표-예시.hwpx`)을 「쌤」 버튼에 끌어 놓기 → 카드에서 알아본 종류·할 일 확인 → [실행]. 설정 › 화면 › 떠 있는 버튼에서 「바로 실행」·「자료로만」으로 바꿀 수 있어요.
1. **단원평가**: 평가 › 단원평가 › [새 단원평가] → [학생 문제지 넣기(스캔한 것)]에 `단원평가-답안-예시.pdf`(학생 한 명 1쪽), [답안 넣기]에 `단원평가-정답지-예시.hwpx`, 「빈 문제지도 있으면 (선택)」 › [빈 문제지 넣기]에 `단원평가지-예시.hwpx` → 다음 → [이름 칸 정하기] → [채점 시작] → 노란 칸 확인 → [채점 마치기] → [잘한 점·격려 쓰기]·[결과지 · 한글로 내려받기]. AI 키 없이 보려면 [예시로 채우기] 뒤 「결과 모아 보기」.
2. **활동지**: 평가 › 활동지 › [새 활동지] → 한꺼번에 넣기에 `활동지-예시.hwpx`(학생용 쪽 + 교사용 쪽) → 나눈 결과 카드 [이대로 넣기] → [다음]에서 AI가 기준 만들기 → 고치고 [기준 확정] → 학생 활동지 스캔 올리기 → [채점 시작] → 노란 칸 확인 → 결과·[확정]. AI 키 없이 보려면 [예시로 채우기].
3. **학급**: 학급 › 진도표·시수 › 준비에서 학년 3, 반 2로 정하고 [시간표 파일에서 가져오기]에 `시간표-예시.hwpx` → [진도표 파일 올리기]에 `진도표-예시.hwpx` → 교과 고르기 → [넣기]. 바로 해 보려면 [예시로 채우기].
4. 학급 › 오늘 수업에서 교시마다 [완료]를 누르고, 진도표·시수에서 진도 차이를 확인해요.
5. 학급 › 주간학습안내에서 다음 주 학습 표를 보고 [AI로 알림 쓰기] → [한글로 내려받기] (옆 [▾]에서 워드·PDF로 바꿀 수 있어요).
6. **학급운영계획**: 계획 › 학급운영계획 › 작년 학급운영계획 [파일 넣기]에 `학급운영계획-작년-예시.hwpx`(담임 명단·연락 줄은 빼고 넣었다고 알려 줘요) → [다음] 작년 목차 그대로 → [다음] [AI로 초안 쓰기] → [다음] [첨부파일 넣기]에 `진도표-예시.hwpx`·`평가계획-예시.hwpx` → 시수표 확인·[학급 › 진도표·시수에도 넣기] → [AI로 평가 표 읽기] → [한글 파일로 내려받기]·[확정]. 바로 해 보려면 [예시로 채우기].
7. **행사계획**: 행사 정보를 넣고 참고 자료에 공문을 붙여 넣은 뒤 [다음] → 구성안 → 문서 → 확정·설문.
8. **품의**: 품의 › 새 품의 넣기 칸에 `3학년 과학 실험 알코올램프 10개 5,000원, 다음 주 화요일 과학실`을 쓰고 [초안 만들기] 한 번 → 초안과 「확인할 것」 칩(예산 과목 등)을 눌러 그 칸만 고치기 → 칸마다 [복사]·[표 복사] → [템플릿으로 저장]. 장바구니 캡처·견적서 파일도 넣기 칸에 넣으면 돼요.
9. **쪽지 작성**: 기타 › 쪽지 작성에 `samples/연수안내-공문-예시.hwpx`를 넣기(또는 「쌤」 버튼에 끌어 놓기) → 안내 쪽지(첫 줄 제목) → [짧게]·[자세히] → 보내는 사람 적기 → [복사] → Windows 앱은 [붙임 파일 복사]·「⠿」 끌어 놓기.
10. **가정통신문**: 기타 › 가정통신문 › [양식 넣기]에 `samples/가정통신문-양식-예시.hwpx`(지어낸 새싹초 양식) → [양식 맞추기]로 자리 보기 → 넣을 내용 몇 줄 → [가정통신문 쓰기] → [한글로 내려받기](양식 머리·로고 그대로).
11. **공문 처리**: 기타 › 공문 처리에 공문 글을 붙여 넣고 [넣기] → 기한·할 일 확인 → 할 일 체크 → [가정통신문]으로 넘어가 [가정통신문 쓰기] → 학급 › 오늘 수업 위 「공문 기한」 띠.
12. **기초학력 캠프**: 학급 › 기초학력 캠프 › [새 캠프] → [계획 파일 넣기]에 운영 계획서(또는 캠프 정보 직접) → 학생 → 수업 일정 [AI로 만들기]에 「1/8~1/23 평일, 9:00~12:40 하루 5교시, 국어·수학」 → 출석 체크에서 칸 누르기 → 문서 내보내기에서 [양식 넣기]에 학교 수업 확인서(.hwpx) → [한글로 내려받기].
13. **다면평가**: 기타 › 다면평가 › 내 정보 → [정량평가]에서 항목마다 숫자 넣기(예: 주당 수업시수 22.8) → 총점 확인 → 항목에 [근거자료 넣기] → [한글로 내려받기]. [정성평가]에 올해 한 일을 줄글로 쓰고 [AI로 넣기](AI가 없으면 [넣기]) → 「입력 필요」 칸 채우기 → 내려받기.
14. **결과 보고**: 계획 › 결과 보고에 계획서·작년 결과 보고서와 행사 사진 몇 장을 넣고 「한 일」을 몇 줄 적기 → [결과 보고 쓰기] → 공문·보고서 칸 고치기 → [한글로 내려받기](사진 자료 포함) → Windows 앱은 [에듀파인 기안에 차례로 붙여넣기].
15. **설정 › 학년도**: [백업 파일 만들기] → [2027학년도 시작하기] → 학년도 목록에서 2026학년도로 돌아오기.

## Windows 앱 떠 있는 버튼 확인 목록 (사람이 직접)

자동 시험은 웹판과 Rust 규칙만 확인해요. Windows 앱에서는 아래를 손으로 확인해 주세요.

1. 탐색기·바탕화면의 파일을 「쌤」 버튼에 끌어 놓으면 버튼이 초록으로 바뀌고, 놓으면 쌤비서 창이 앞으로 나와 확인 카드가 떠요. 폴더를 놓으면 아무 일도 없어요.
2. 버튼을 끌면 옮겨지고(누른 것으로 치지 않음), 그냥 누르면 쌤비서 창이 열려요. 앱을 다시 켜도 옮긴 자리에 있어요.
3. 오른쪽 클릭: 쌤비서 열기 · 파일 고르기(쌤비서 창에 [파일 고르기] 카드) · 버튼 숨기기(설정 › 화면에서 다시 켜기) · 쌤비서 끝내기. 항목마다 눌렀을 때 바로 그대로 되는지 확인해 주세요(0.8.0까지는 반응이 없었음).
4. 설정 › 화면 › 떠 있는 버튼 「쌤비서 창을 닫아도 버튼은 남기기」 켬: 창을 닫으면 버튼만 남고, 버튼을 누르면 창이 다시 열려요. 끔: 창을 닫으면 앱이 끝나요.
5. 「컴퓨터를 켜면 버튼 띄우기」 켜고 다시 로그인: 버튼만 뜨고 쌤비서 창은 안 보여요. 버튼을 끈 채면 자동으로 켜지지 않아요.
6. 쌤비서가 켜져 있을 때 바탕화면 아이콘으로 또 켜면 새 창 없이 켜진 쌤비서가 앞으로 나와요.
7. 버튼 메뉴 「버튼 숨기기」를 쌤비서 창이 숨은 채로 누르면 쌤비서 창이 보여요(창이 하나도 없는 채로 남지 않음).
8. 설정을 바꿀 때 버튼이 포커스를 빼앗지 않아요. 업데이트는 쌤비서 창이 숨어 있어도 다음에 켤 때 적용돼요.
9. 버튼을 누르고 Alt+F4를 눌러도 앱이 끝나지 않고 「버튼 숨기기」와 같아요(설정 › 화면에서 다시 켜기). 같은 파일을 잇달아 두 번 놓으면 카드는 한 번만 떠요.
10. 쌤비서 창 안으로 파일을 끌고 오면 오른쪽 아래 버튼이 조금 커지고, 버튼 근처에서만 놓기 판이 떠요. 판이 아닌 곳에 놓아도 창이 파일로 바뀌지 않아요.
11. 설정 › 프로그램 삭제를 하면 「컴퓨터를 켜면 버튼 띄우기」도 꺼져요.
12. 쌤비서 창이 막 켜지는 중에 놓은 파일이 카드로 안 뜨면 같은 파일을 다시 놓으면 받아요(3초 안에 잇달아 두 번 알려도 카드는 하나, 읽지 못한 파일은 바로 다시 놓을 수 있음). 설정 › 화면에서 테마를 바꾸면 바탕화면 버튼 색도 바로 바뀌어요.

## 개인정보와 AI

- 자료는 쓰는 사람의 컴퓨터(브라우저 저장소, 지난 학년도는 브라우저 보관함)에만 저장돼요. 쌤비서 서버는 없어요.
- AI 요청은 그 컴퓨터에서 AI 회사로 바로 가요. AI 키는 이 컴퓨터에만 저장되고 레포·백업 파일에 들어가지 않아요.
- 평가지·학습지·단원평가 답안은 이름 칸을 가리고 AI에 보내요. 단원평가 피드백·평어에는 번호·점수·평가 내용만 보내요. 학급 명단은 번호만 쓰고, 설문 CSV의 이름·학번 열은 AI로 보내지 않아요.
- 레포의 시연 자료는 모두 지어낸 예시예요.

## 개발

```bash
npm install
npm run web          # web/ → dist/
npm test             # 함수 시험 (node --test)
npm run e2e          # 화면 시험 (Playwright)
npm run samples      # samples/ 다시 만들기
npm run tauri build -- --bundles nsis   # Windows 앱 (Windows에서)
```

- 기획과 요구사항: [docs/PRD.md](docs/PRD.md) · 설계: [docs/superpowers/specs/](docs/superpowers/specs/) · 구현 계획: [docs/superpowers/plans/](docs/superpowers/plans/)
- 구조: 빌드 도구 없는 `web/`(ES 모듈) + Tauri 2 Windows 앱. 메뉴마다 `web/menus/<메뉴>/`, 공통은 `web/core/`.

## 배포

- **Windows 앱**: Actions → 「Windows 앱 빌드·릴리즈 (쌤비서)」를 「릴리즈 만들기」를 켜고 실행하면 `package.json` 버전으로 릴리즈를 만들고 설치 파일·`latest.json`을 올려요. 바뀐 점은 `.github/RELEASE_NOTES.md`의 `whats-new` 사이에 적어요.
- **웹판**: main에 올릴 때마다 `web/` 폴더가 GitHub Pages로 배포돼요.
