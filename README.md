# 쌤비서

선생님의 평가·계획·학급 업무를 왼쪽 세로 메뉴 하나에 모은 교사용 AI 업무 앱입니다. AI가 초안을 쓰고, 선생님은 확인하고 고치기만 하면 됩니다.

- 2026 한국형-AI 기반 교사개발자 연수 예선 출품작 (3기-4조)
- 만든이: 도구리 · 연락처: raccoon@ai.cne.go.kr

## 써 보기

- **웹판(설치 없이)**: https://doguri25.github.io/ssam-assistant/
- **Windows 앱**: [릴리즈](https://github.com/doguri25/ssam-assistant/releases)에서 `ssam-<버전>-setup.exe`(설치) 또는 `ssam-<버전>-portable.exe`(설치 없이 실행). 앱이 새 버전을 스스로 확인해요.
- AI는 설정 › AI에서 Claude·Gemini·GPT·업스테이지(Solar) 중 하나의 키를 넣고 [연결 확인]을 눌러요.
  - 진도표·시간표 가져오기, 진도·시수 계산, 체크, 한글 파일 만들기처럼 AI 없이 되는 일도 많아요.

## 메뉴마다 되는 일

| 메뉴 | 되는 일 |
|---|---|
| **평가** | 교과 평어 · 창의적 체험활동 · 행동특성 및 종합의견 · 평가지 채점(스캔한 평가지·학습지를 AI가 읽고 채점), 나이스 입력 돕기. 「평어 만들기 1.8.0」에서 출발 |
| **평가 › 단원평가** | 정답지(문항 이원 분류표)를 AI 없이 읽고, 반 전체 답안 스캔을 문항마다 채점(AI는 답을 읽고 앱이 정답과 맞춤, 서술형은 부분 점수) → 노란 칸만 확인 → 학생 결과지(틀린 문항·교과서 쪽·잘한 점·격려)와 번호별 글 → 성적 일람표·학생별 누적·반 약한 부분·교과 평어 초안 |
| **계획 › 연간계획** | 작년 계획서·결과·올해 지침 → 작년 평가 → 지침 점검(빠진 것 넣기) → 초안(작년과 겹치는 정도) → 월별 일정(공휴일·방학·다른 일정과 겹침, 추천 날짜) → 한글 파일·확정(학사일정에 넣기) |
| **계획 › 행사계획** | 행사 정보·참고 자료(상위 계획·교육청 공문) → 구성안 2~3개 → 계획서·역할 분담표·안전 점검표·가정통신문 → 확정·만족도 설문(구글 폼 문항, QR, 응답 CSV로 결과 보고서·내년 개선 메모) |
| **학급 › 진도표·시수** | 학교의 「교과-창체 연간지도계획」·「학년별 기초시간표」 한글 파일을 AI 없이 읽어 교과 진도표와 우리 반 시간표를 넣고, 교과별 계획·실시·남은 시수와 진도 차이(+1, −2)를 보여 줘요 |
| **학급 › 오늘 수업** | 교시마다 교과·단원·차시·학습 주제를 보이고 [완료 / 일부 진행 / 못 함]만 누르면 시수와 진도가 계산돼요 |
| **학급 › 주간학습안내** | 진도표대로 이어지는 다음 주 학습 내용 + 요일별 알림(학사일정·준비물·과제·안내장·안전)을 한글 파일·인쇄·복사로 |
| **설정** | 학급 명단(엑셀·CSV에서 번호만), AI, 화면 테마 5가지, 학교 정보, 학년도(백업 파일·학년도 오가기·새 학년도 시작), 품의 기준 |
| 연수 · 품의 | 다음 버전에서 채워요 (품의는 새 품의 화면만 있어요) |

## 시연 순서 (샘플 파일: [`samples/`](samples/), 모두 지어낸 예시)

1. **단원평가**: 평가 › 단원평가 › [새 단원평가] → [정답지 넣기]에 `단원평가-정답지-예시.hwpx`, [평가지 넣기]에 `단원평가지-예시.hwpx` → 다음 → [답안 스캔 올리기]에 `단원평가-답안-예시.pdf`(학생 한 명 1쪽) → [이름 칸 정하기] → [채점 시작] → 노란 칸 확인 → [채점 마치기] → [잘한 점·격려 쓰기]·[결과지 한글 파일]. AI 키 없이 보려면 [예시로 채우기] 뒤 「결과 모아 보기」.
2. **학급**: 학급 › 진도표·시수 › 준비에서 학년 3, 반 2로 정하고 [시간표 파일에서 가져오기]에 `시간표-예시.hwpx` → [진도표 파일 올리기]에 `진도표-예시.hwpx` → 교과 고르기 → [넣기]. 바로 해 보려면 [예시로 채우기].
3. 학급 › 오늘 수업에서 교시마다 [완료]를 누르고, 진도표·시수에서 진도 차이를 확인해요.
4. 학급 › 주간학습안내에서 다음 주 학습 표를 보고 [AI로 알림 쓰기] → [한글 파일].
5. **행사계획**: 행사 정보를 넣고 참고 자료에 공문을 붙여 넣은 뒤 [다음] → 구성안 → 문서 → 확정·설문.
6. **설정 › 학년도**: [백업 파일 만들기] → [2027학년도 시작하기] → 학년도 목록에서 2026학년도로 돌아오기.

## 개인정보와 AI

- 자료는 쓰는 사람의 컴퓨터(브라우저 저장소, 지난 학년도는 브라우저 보관함)에만 저장돼요. 쌤비서 서버는 없어요.
- AI 요청은 그 컴퓨터에서 AI 회사로 바로 가요. AI 키는 이 컴퓨터에만 저장되고 레포·백업 파일에 들어가지 않아요.
- 평가지·학습지·단원평가 답안은 이름 칸을 가리고 AI에 보내요. 단원평가 피드백·평어에는 번호·점수·평가 내용만 보내요. 학급 명단은 번호만 쓰고, 설문 CSV의 이름·학번 열은 AI로 보내지 않아요.
- 레포의 시연 자료는 모두 지어낸 예시예요.

## 개발

```bash
npm install
npm run web          # web/ → dist/
npm test             # 함수 시험 (node --test)
npm run e2e          # 화면 시험 (Playwright)
npm run samples      # samples/ 다시 만들기
npm run tauri build -- --bundles nsis   # Windows 앱 (Windows에서)
```

- 기획과 요구사항: [docs/PRD.md](docs/PRD.md) · 설계: [docs/superpowers/specs/](docs/superpowers/specs/) · 구현 계획: [docs/superpowers/plans/](docs/superpowers/plans/)
- 구조: 빌드 도구 없는 `web/`(ES 모듈) + Tauri 2 Windows 앱. 메뉴마다 `web/menus/<메뉴>/`, 공통은 `web/core/`.

## 배포

- **Windows 앱**: Actions → 「Windows 앱 빌드·릴리즈 (쌤비서)」를 「릴리즈 만들기」를 켜고 실행하면 `package.json` 버전으로 릴리즈를 만들고 설치 파일·`latest.json`을 올려요. 바뀐 점은 `.github/RELEASE_NOTES.md`의 `whats-new` 사이에 적어요.
- **웹판**: main에 올릴 때마다 `web/` 폴더가 GitHub Pages로 배포돼요.
