# 평가 › 단원평가 설계 (자동채점·학생 피드백·결과 쌓기)

- 날짜: 2026-10-29
- 요청(선생님): 단원평가지와 정답지를 올리면 학생 답안을 자동채점하고 피드백을 준다. 양식은 선생님이 보낸 「3학년 2학기 국어 1단원 단원평가(1회)」·「문항 이원 분류 및 모범 답안」 한글 파일 모양을 따르되, 조금씩 다를 수 있다.
- 결정(2026-10-29 질의)
  - 평가 메뉴에 **새 탭 「단원평가」**.
  - 피드백은 **학생에게**: 인쇄해 나눠 줄 **개인 결과지**와 하이클래스·알림장에 붙일 **번호별 글**을 둘 다.
  - 피드백 내용: **점수와 틀린 문항**, **틀린 문항의 평가 내용·교과서 쪽**, **잘한 점과 격려 한마디**. (비슷한 문제 만들기는 하지 않음)
  - 서술형: AI가 **부분 점수**까지 제안하고 선생님이 확인.
  - 결과 쌓기: **학기 성적 일람표**, **학생별 누적**, **반 전체 약한 부분**, **교과 평어로 넘기기**.
- 선생님이 보낸 실제 파일은 레포에 넣지 않는다. 시연·시험 자료는 같은 모양으로 지어낸다.

## 1. 양식 (선생님 파일에서 읽은 모양)

### 1.1 정답지 = 「문항 이원 분류 및 모범 답안」 표
- 제목 줄: `2학기 단원평가 문항 이원 분류 및 모범 답안 ( 3 )학년 ( 국어 )과 1단원 (1회)` → 학기 2, 학년 3, 교과 국어, 단원 1, 회차 1.
- 머리 줄 2개: `문항번호 | 평가 내용 | 행동 영역 | 정답 | 배점 및 채점 기준 | 교과서 관련 쪽수`, 다음 줄 `지식 | 이해 | 배점 | 채점 기준`.
  - 행동 영역 이름은 교과마다 다를 수 있다(예: 계산·이해·추론·문제 해결). 둘째 머리 줄에서 「배점」 앞의 칸들이 영역 이름이다.
- 문항 줄: `번호 | 평가 내용 | (영역마다 ○ 또는 빈칸) | 정답 | 배점 | 채점 기준 | 교과서 쪽`.
  - 예: `4 | 시의 내용을 파악하고 자신의 생각 쓰기 |  | ○ | (예) (1) … (2) … 등 | 8 | (1)에 예시 답안과 비슷한 내용으로 쓰고 … 정답 처리 | <국어> 36~41쪽`
- 정답 모양: `③`, `③, ⑤`(두 개 고르기), `(3) ○`(○표), `㉯`(기호), `(1) - ①  (2) - ②`(선 잇기), `준호`·`바이올렛이 최고`(단답), `(예) …`(서술형).

### 1.2 평가지
- 머리: `국어 3-2 | 1. 경험과 관련지으며 이해해요 (1회) | 초등학교 학년 반 번 이름:` → 교과·학년·학기·단원 번호·단원 이름·회차. 오른쪽 위에 이름 칸.
- 지문(`※ 다음 시를 읽고 물음에 답하시오. (1~2)`) 다음에 문항. 문항은 번호만 있는 줄(1, 2, 3 …차례로)로 시작하고, 그다음 줄이 발문.
- 학생은 평가지에 바로 답을 쓴다(괄호·빈칸·표 칸·선 잇기).

## 2. 화면 (평가 › 단원평가)

탭 안에서 위쪽 두 갈래: **평가 목록**(기본) · **결과 모아 보기**.

### 2.1 평가 목록
- 쌓인 단원평가 카드: 제목(「3학년 국어 1단원 경험과 관련지으며 이해해요 (1회)」), 날짜, 학생 수, 반 평균, 상태(채점 중 / 마침).
- [새 단원평가], [예시로 채우기](지어낸 평가 2개를 채점·피드백까지 끝난 모양으로 넣음: AI 키 없이 결과 화면을 볼 수 있게).
- 카드를 누르면 그 평가의 단계 화면. [지우기](확인 창).

### 2.2 새 단원평가 — 4단계 (`core/steps.js`)
1. **정답지·평가지**
   - [정답지 넣기]: 한글(.hwp·.hwpx)·PDF(글자)·사진. 이원 분류표 모양이면 **AI 없이** 표로 읽는다. 못 읽으면(모양이 다름·사진·스캔 PDF) AI가 읽는다.
   - [평가지 넣기](선택): 한글·PDF. 머리에서 교과·학년·단원·회차를 채우고, 문항 발문을 AI 채점과 피드백에 쓴다.
   - 정답표 확인: 문항마다 번호·평가 내용·영역·유형·정답·배점·채점 기준·교과서 쪽을 칸으로 보이고 고칠 수 있다. 위에 「20문항 · 100점」, 배점 합이 100이 아니면 알림(막지는 않음). [문항 더하기]·[빼기].
   - 평가 정보: 교과, 학년, 단원 번호·이름, 회차, 날짜(기본 오늘). 제목은 이것으로 만든다.
2. **답안 올리기**
   - 반 전체 스캔 PDF나 사진 여러 장. 「학생 한 명 ○쪽」(기본 2)으로 나누고, 학급 명단(설정 › 학급 명단, `ssam:class`)의 예외 번호를 건너뛰며 1번부터 번호를 매긴다. 번호는 고칠 수 있고 [채점 안 함]도 둔다.
   - **이름 칸 가리기**: 평가지 채점과 같은 편집기(끌어서 상자). 기본은 첫 쪽만 가림, 모든 쪽 가리기 선택. 가린 자리는 이 평가에 저장해 다음 회차에도 쓴다(`unit:set`).
   - 스캔 이미지는 이 화면에만 있고 저장하지 않는다.
3. **채점·확인**
   - [채점 시작]: 학생마다 AI 요청 1번(차례로, 동시에 2명). 진행 「12/25명」, [멈추기]. 실패한 학생은 「다시」.
   - **확인 표**: 줄 = 학생 번호, 칸 = 문항. 칸에는 ○(만점)·✕(0점)·부분 점수(예 `4/8`)·빈 답 `—`. 끝 칸에 총점.
     - 노란 칸 = 확인할 것: AI가 확신이 낮음, 앱과 AI 판단이 다름, 단답이 정답과 글자가 달라 AI가 뜻으로 판단함, 서술형(선생님이 확인하기 전까지).
     - 칸을 누르면 시트: 학생이 쓴 답(AI가 읽은 글, 고칠 수 있음), 정답·채점 기준, AI의 이유, 점수(0~배점 단추, 서술형은 숫자), 그 학생 평가지 이미지(있을 때). [확인]을 누르면 노란색이 풀린다.
     - 문항 머리를 누르면 **문항 모아 보기**: 그 문항의 반 전체 답·점수를 한 화면에. [AI 점수로 모두 확인].
     - 위에 「확인할 칸 7개」, [다음 확인할 칸].
   - [채점 마치기]: 확인할 칸이 남아 있으면 「확인하지 않은 칸 7개가 있어요. 그대로 마칠까요?」. 마치면 결과 모아 보기에 들어간다. 마친 뒤에도 고칠 수 있다.
4. **피드백**
   - [잘한 점·격려 쓰기](AI): 학생마다 「잘한 점」 1문장, 「격려 한마디」 1문장. 고칠 수 있다. 이미 쓴 학생은 건너뛰고 [다시 쓰기]는 고른 학생만.
   - 학생마다 미리 보기: 점수, 틀린 문항 표(문항 · 평가 내용 · 내 답 · 정답 · 다시 볼 곳(교과서 쪽)), 부분 점수 문항, 잘한 점, 격려.
   - [결과지 한글 파일]: 한 쪽에 학생 2명(가운데를 잘라 나눠 줌). 학생 이름은 쓰지 않고 「○번」.
   - [인쇄]: 같은 모양을 `window.print`(한 쪽에 2명).
   - [번호별 복사]: 학생마다 [복사] 단추, [모두 복사](번호마다 빈 줄로 나눔).

### 2.3 결과 모아 보기
- 위쪽 거르기: 교과(전체/국어/수학…), 학기(1학기/2학기/전체 — 평가 날짜로 3~8월이 1학기).
- **성적 일람표**: 줄 = 번호, 칸 = 평가(교과별로 묶고 단원·회차 차례), 끝 칸 = 평균(100점으로 환산). 맨 아래 반 평균. [엑셀(CSV)]·[한글 파일].
- **학생별 누적**: 번호 고르기 → 평가마다 날짜·제목·점수·반 평균, 영역별 정답률(지식/이해 …), 자주 틀린 평가 내용(잃은 점수가 큰 차례 5개). [복사](상담용 글).
- **반 약한 부분**: 평가 고르기(기본 가장 최근) → 문항별 정답률(낮은 차례), 영역별 정답률, 객관식·기호 문항에서 많이 쓴 오답, 「다시 가르칠 내용」(정답률 60% 아래 문항의 평가 내용·교과서 쪽).
- **교과 평어로 넘기기**: 교과 고르기 → 넣을 평가 체크(기본 그 교과 모두) → 학생마다 평균 점수로 수준(최상 ≥ 95, 상 ≥ 80, 중 ≥ 60, 하 < 60 — 기준 고칠 수 있음, 수준도 학생마다 고칠 수 있음) → [평어 쓰기](AI) → 학생마다 교과학습발달상황 문장 초안, 번호별 [복사]·[모두 복사]. 저장해 두고 다시 열 수 있다.

## 3. 채점 규칙

### 3.1 문항 유형 (정답에서 저절로, 고칠 수 있음)
| 유형 | 정답 예 | 맞는 조건 |
|---|---|---|
| 고르기(choice) | `③`, `③, ⑤`, `(3) ○` | 학생이 고른 번호 묶음 = 정답 번호 묶음 (순서 무관, ③·3·(3) 같게) |
| 기호(symbol) | `㉯`, `㉠, ㉢` | 기호 묶음이 같음 (㉯·나·(나) 같게, ㉠·ㄱ 같게) |
| 선 잇기(match) | `(1) - ①  (2) - ②` | 모든 짝이 같음 |
| 단답(short) | `준호`, `바이올렛이 최고` | 띄어쓰기·문장부호를 빼고 같음. `/`나 「또는」으로 나뉜 답은 그중 하나. 다르면 AI가 같은 뜻인지 판단(노란 칸) |
| 서술형(essay) | `(예) …`, 채점 기준이 있음 | AI가 채점 기준·예시 답안으로 0~배점 점수 제안(노란 칸) |
- 고르기·기호·선 잇기는 부분 점수가 없다(양식에 없음). 서술형만 부분 점수.
- 유형 짐작: `(예)`로 시작하거나 채점 기준이 있으면 서술형 → 정답이 동그라미 숫자뿐이면 고르기 → `(n) ○`꼴이면 고르기 → `(n) - ①`꼴이면 선 잇기 → 기호뿐이면 기호 → 나머지는 단답.

### 3.2 AI가 하는 일과 앱이 하는 일
- 학생 한 명마다 AI에게: 그 학생의 평가지 이미지(이름 칸 가림), 정답표(번호·유형·정답·배점·채점 기준), 평가지 글(있으면, 12,000자까지), 「이 학생은 3번」.
- AI 답(JSON): 문항마다 `read`(학생이 쓴 답을 그대로, 빈칸이면 ""), `points`(AI가 본 점수), `sure`(true/false), `why`(서술형·단답 판단 이유, 40자 안팎).
  - 고르기는 고른 번호를 `③`처럼, ○표는 ○표 한 보기를 `(3)`처럼, 선 잇기는 `(1)-①, (2)-②`처럼 적게 한다.
- 앱: 고르기·기호·선 잇기·단답(글자가 같을 때)은 `read`와 정답을 비교해 **앱이 점수를 정한다**. AI 점수와 다르면 노란 칸(「AI는 맞다고 봄」).
  - 단답이 글자가 다르면 AI 점수(0 또는 배점)를 쓰고 노란 칸.
  - 서술형은 AI 점수(0~배점 정수로 자름)를 쓰고, 선생님이 확인하기 전까지 노란 칸.
  - `sure: false`면 노란 칸. 빈 답은 0점, 노란 칸이 아님.
- 선생님이 고친 점수(`manual`)는 다시 채점해도 덮지 않는다(다시 채점하면 묻는다).

### 3.3 잘한 점·격려 (AI, 글만)
- 학생마다 보내는 것: 번호, 점수/만점, 맞힌 문항의 평가 내용, 틀리거나 부분 점수인 문항의 평가 내용, 학년. 이미지·이름 없음. 10명씩 묶어 한 번에.
- 규칙: 그 학년 학생에게 하는 말(「~했어요」), 잘한 점은 맞힌 평가 내용에 근거, 격려는 틀린 내용을 다시 보도록 따뜻하게, 각 60자 안팎, 이름·점수 숫자를 쓰지 않음.

### 3.4 교과 평어 (AI, 글만)
- 학생마다: 번호, 수준, 잘한 평가 내용(정답률 높은 것), 보완할 평가 내용, 교과. 10명씩.
- 규칙: 교과학습발달상황 문장 1~2문장(80~150자), 끝맺음 「~함.」「~임.」, 학생 이름·대명사·점수를 쓰지 않음, 하 수준도 「~하면 더 나아질 것임」처럼 성장 중심. 수준이 같아도 학생마다 다른 문장.

## 4. 저장 (학년도마다 따로 — 설정 › 학년도와 백업 파일에 들어감)
- `unit:list`: `[{ id, title, subject, grade, term, unitNo, round, date, total, n, avg, done }]` (목록·일람표를 빨리 그리려고 요약을 둠).
- `unit:t:<id>`: `{ id, meta: { subject, grade, term, unitNo, unitName, round, date }, key: { domains: ['지식','이해'], items: [{ no, content, domain, type, answer, points, criteria, pages }] }, paper: { text }, students: [{ no, skip, items: { [no]: { read, pts, ai, flag, why, ok } }, good, cheer }], done, createdAt }`.
  - `flag`: `'low' | 'differ' | 'similar' | 'essay' | ''`, `ok`: 선생님이 확인함(노란색 풀림), `manual`: 선생님이 고친 점수.
  - 글 길이를 줄여 저장: `read` 120자, `why` 80자, 평가지 글 12,000자. 한 평가에 약 50KB.
- `unit:set`: `{ pagesPer, mask, maskAll, maskOn }` (지난 평가의 나누기·가리기).
- `unit:pyeongeo:<교과>`: `{ tests: [id], cuts: { top, high, mid }, students: { [no]: { level, text, manual } } }`.
- 저장에 실패하면(공간 부족) 「저장 공간이 모자라 저장하지 못했어요」. 새 학년도에는 가져가지 않는다(학생 자료).

## 5. 개인정보·AI
- 이름 칸은 가려서 보낸다(기본 켬). 학생은 번호로만 다룬다. 결과지·글에도 이름을 쓰지 않는다.
- 스캔 이미지는 저장하지 않는다. 다시 열면 확인 시트에 「스캔 이미지는 저장하지 않아서 지금은 볼 수 없어요」.
- 손글씨는 Claude·Gemini·GPT를 권장(업스테이지는 이미지를 글자로 바꿔 보내므로 정확도가 낮다는 안내를 채점 단계에 보임).

## 6. 기존 코드와 잇기
- 평가 메뉴 탭에 `['unit', '단원평가']`. 기존 평가 화면(평어·창체·행특·채점)은 기존 `setMode`로, 「단원평가」는 새 모듈이 그린다. 단원평가 탭일 때 기존 화면을 숨기고(평가 구역에 표시 class), 기존 손잡이(행특·채점)도 쉬게 한다(`evalShown()`).
- 스캔 읽기·이름 가리기는 기존 평가지 채점 코드를 `window.SSAM`으로 꺼내 쓴다: `files.readPages(files, say)`, `files.pageImage(page, mask)`, `files.freePages(pages)`, `openMaskEditor(...)`.
- AI는 `core/ai.js`(`generateJSON`), 글 읽기는 `core/files.js`(`readText`), 한글 파일은 `core/hwpx.js`(쪽 나누기 블록 `{ type: 'break' }`를 더함), 표 내보내기는 CSV.
