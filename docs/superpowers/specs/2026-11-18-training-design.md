# 연수 메뉴 만들기 (2026-11-18)

선생님 요청: 「연수쪽도 진행해주고 학급도 진행해줘. 그리고 각 정보와 메뉴가 유기적으로 돌아가는지 확인해줘」.
지금 연수 메뉴는 탭 두 개(내 필수연수·연수 현황판)에 「곧 만들어요」만 있음. PRD 5.5(T-1·T-2)와 아픈 곳 「이수증을 메신저로 받고 엑셀에 한 명씩 체크한다」를 바탕으로 만든다.
정한 것은 제 판단(선생님이 맡김). 쌤비서는 선생님 컴퓨터마다 따로 도는 앱(서버 없음)이라, 내 필수연수는 「나」의 기록, 연수 현황판은 「연수 담당 선생님」의 기록이다.

## 원칙

- **AI 없이** 돈다. 이수증·명단은 이 컴퓨터 안에서만 읽고, 교직원 이름은 AI로 보내지 않는다(이 메뉴는 AI를 부르지 않음).
- 이수증 파일 자체는 저장하지 않는다(브라우저 저장 공간이 작음) — 파일 이름·이수일·시간만 남기고 「파일은 컴퓨터에 그대로 두세요」.
- 법정 연수 시간·주기 같은 숫자는 지어 쓰지 않는다(학교·교육청마다 다름) — 기본 목록은 이름만, 시간·기한은 선생님이 공문을 보고 넣음.
- 저장은 학년도 자료(`training:mine`, `training:board`).

## 1. 내 필수연수 (tab `mine`)

- 연수 줄: `{ id, title, hours, due, where, status, doneDate, cert, note, from, at }`
  - status: `todo`(미이수) → `done`(이수함 — 이수증 있음) → `sent`(제출함) → `ok`(확인 완료) / `back`(반려, note에 사유). PRD의 네 상태 + 이수함.
  - from: 공문에서 넣었으면 `gongmun:<id>`.
- 맨 위 요약: 「올해 필수연수 n개 중 m개 이수 · 이수 시간 h시간」, 기한 지난 미이수가 있으면 빨갛게.
- [+ 연수 더하기](이름·기한·시간·곳), [기본 목록 넣기](법정 의무연수 이름 11개 — 이미 있는 이름은 빼고), 줄마다 [이수증 넣기]·상태 단추·[고치기]·[지우기].
- **이수증 넣기**(줄 하나에, 또는 맨 위 칸에 여러 개): 한글·PDF·워드·글 파일은 글을 읽어(AI 없이) 연수 이름과 맞는 줄을 찾고 이수일(「이수일·수료일·교육 기간」 근처 날짜, 없으면 글 속 마지막 날짜)과 시간(「n시간」「n차시」)을 채운 뒤 `done`. 사진·스캔은 파일 이름으로만 맞춤. 못 맞추면 어느 줄인지 고르게.
- 차례: 미이수(기한 가까운 것 먼저) → 이수함 → 제출함 → 확인 완료.
- 기한 → 학사일정 `training` 출처 일정 「[연수] ○○ 이수 기한」(이수함 뒤로는 뺌). 학부모 안내(주간학습안내)에는 넣지 않음.

## 2. 연수 현황판 (tab `board`) — 연수 담당 선생님

- `{ staff: [{ id, name, dept }], courses: [{ id, title, due }], marks: { [courseId]: { [staffId]: { s, file, at, note } } } }`, s: `sent`(제출)·`ok`(확인)·`back`(반려)·없음(미제출).
- **교직원 명단**: [명단 붙여 넣기](한 줄에 한 명, 「이름 ⇥ 부서」 엑셀 붙여넣기도) 또는 명단 파일(엑셀·CSV — 「이름·성명」 열, 「부서·소속·직위」 열은 부서로). 같은 이름 두 번은 한 번만(부서가 다르면 둘 다). 「명단은 이 컴퓨터에만 두고 AI로 보내지 않아요」.
- **연수**: [+ 연수 더하기](이름·기한), [기본 목록에서 고르기].
- **상태표**: 교직원 × 연수. 칸을 누르면 미제출 → 제출 → 확인 → 미제출. 연수 머리 칸을 누르면 그 연수 시트: 이름·기한 고치기, 사람마다 상태 고르기(반려는 사유), [제출한 사람 모두 확인], [지우기].
- 연수마다 이수율 막대: 「제출·확인 n/전체 (n%) · 미제출 n · 반려 n」.
- **이수증 한꺼번에 넣기**(파일 여러 개 끌어 놓기): 파일 이름과(한글·PDF·워드면) 글에서 명단의 이름과 연수를 찾아 맞춤 → 그 칸 「제출」, 파일 이름을 남김.
  - 이름: 명단 이름이 파일 이름·글에 그대로 있으면(띄어 쓴 「김 하늘」도). 둘 이상이면 파일 이름 쪽, 그래도 둘 이상이면 못 맞춤.
  - 연수: 연수 이름의 낱말(「교육·연수·예방·이수증·수료증·온라인·과정」 빼고)이 가장 많이 겹치는 것, 연수가 하나뿐이면 그것.
  - 결과 카드: 「12개를 맞췄어요 · 3개는 못 맞췄어요」, 못 맞춘 파일마다 사람·연수를 골라 [넣기].
- **독려 쪽지**: 연수 시트의 [독려 쪽지] → 「[제출 안내] ○○ 이수증 제출 안내」, 인사, 「□ 기한: 2026. 11. 30.(월)까지」, 「아직 이수증을 내지 않으신 선생님께서는 이수 후 이수증을 보내 주세요.」, 「감사합니다.」를 AI 없이 만들어 [복사]·[쪽지 작성에서 다듬기](문서·소통 › 쪽지 작성에 그 글을 넣음 — 이름 없음). 미제출 명단은 [미제출 명단 복사]로만(컴퓨터 안에서 복사).
- **엑셀 내려받기**: CSV(엑셀에서 열림) 「이름, 부서, 연수1, 연수2, …」 칸은 제출·확인·반려·(빈칸), 맨 아래 줄 이수율.

## 3. 다른 메뉴와 잇기

- **공문 처리**: 연수 공문(제목·요약·할 일에 연수·교육이 있고 이수·수료·이수증 말이 있는 것)이면 이어 쓰기 단추 줄에 [내 필수연수에 넣기]·[연수 현황판에 넣기] — 이름은 공문 제목에서 「안내·알림·실시·협조·…에 대한」 같은 꼬리를 뺀 것, 기한은 공문 기한(없으면 기한 있는 할 일). 이미 넣은 공문이면 「넣었어요」.
- **오늘 화면·채팅 「오늘 할 일」**(briefing): 미이수 연수의 기한이 지났거나 14일 안이면 「필수연수 「○○」 이수」 D-n(누르면 내 필수연수), 현황판 연수의 기한이 7일 안이고 미제출이 있으면 「연수 현황 「○○」 미제출 n명」(누르면 현황판). 학사일정 줄에서는 `training` 일정을 빼서 두 번 나오지 않게.
- **주간학습안내**: 학부모께 가는 학사일정은 행사계획·직접 넣은 일정만(공문·연간계획·연수 일정은 빼는 쪽을 넘어, 보호자용으로 정해진 출처만 넣음).
- **「쌤」 채팅**: 「필수연수」「이수증」「연수 현황」 → 연수 메뉴 안내와 단추, 「연수 몇 개 남았어?」는 AI 없이 「미이수 n개(가장 가까운 기한 ○○ D-n)」.
- **인수인계서**: 연수 현황판에 연수가 있으면 「연수 현황」 줄(연수마다 이름·기한·이수율 — 사람 이름 없음).
- 학년도 바꾸기: 새 학년도로 넘길 때 현황판 명단은 가져갈 수 있게(연수·상태는 새로).

## 4. 연수 수합 (2026-11-19 선생님 요청 「연수 수합도 해야 하는데 가능할까?」)

선생님 답: 만들어 낼 것 — 이수증 파일 묶음·내부결재 결과 보고·교육청 실적 제출·엑셀 명단표 모두. 받는 방법 — 메신저 파일·구글 폼·종이.

- **구분**: 교직원마다 교원·직원·공무직(명단의 부서·직위 글로 짐작 — 「교사·담임·n학년·교감」은 교원, 「행정실·주무관」은 직원, 「실무사·조리·돌봄·공무직」은 공무직, 명단 시트에서 고침).
- **연수 대상**: 연수마다 전 교직원(기본) 또는 교원·직원·공무직 중 고른 것. 대상이 아닌 칸은 「—」(누르지 않음), 이수율·미제출은 대상만 셈.
- **받기**
  - 메신저 파일: 지금처럼 끌어 놓기. ZIP(구글 드라이브 폴더 내려받기)도 풀어서 파일마다 맞춤. 구글 폼 파일 이름 「원래 이름 - 응답자.pdf」도 이름으로 맞춤.
  - 구글 폼: [설문 응답 넣기](CSV·엑셀) — 「이름·성명·성함」 열로 사람, 연수 열(머리에 연수·교육·과정)이 있으면 그 연수, 없으면 고른 연수, 파일 열(드라이브 주소)은 칸에 링크로 남김. 못 맞춘 줄은 고르기.
  - 종이: 칸 누르기(지금처럼).
  - 이수증 글에서 읽은 이수일·시간은 그 칸에 남김(명단표·결과 보고 명단에).
- **파일 보관**: 맞춘 이수증 파일은 이 기기(IndexedDB `ssam-forms-training`, 학년도마다 이름 앞에 학년도)에만, 5MB까지. 백업 파일에는 들어가지 않음. 칸을 미제출로 돌리거나 사람·연수를 지우면 그 파일도 지움.
- **만들어 내기**(현황판의 「수합 마무리」 칸)
  - **이수증 묶음(ZIP)**: `연수명/연수명_이름(부서).확장자` + `이수 현황.csv`. 파일이 없는 제출(종이·구글 폼 링크)은 CSV에 「종이·링크」로.
  - **결과 보고(한글·워드·PDF)**: 고른 연수로 내부결재 본문 — 제목 「2026학년도 ○○ 이수 결과 보고」(여럿이면 「○○ 등 법정의무교육」), 1. 관련(연수를 공문에서 넣었으면 그 공문), 2. 「… 결과를 다음과 같이 보고합니다.」 가. 연수명 나. 대상(구분별 인원) 다. 이수 현황 표(연수 | 대상 | 이수 | 미이수 | 이수율) 라. 미이수(개별 안내), 붙임 1. 이수 현황 명단 1부. 2. 이수증 n부. 끝. + 명단 표(연번 | 이름 | 구분 | 부서 | 연수마다 이수일·미이수). AI를 부르지 않음(이름이 들어가는 문서라 컴퓨터 안에서만).
  - **교육청 실적 표**: 연수마다 구분(교원·직원·공무직·계) × 대상·이수·이수율 — [표 복사](한글·엑셀 표에 붙여 넣기), 엑셀 내려받기에도. 공문 양식 칸을 저절로 채우지는 않음(양식마다 달라 표를 붙여 넣음).
  - **엑셀 명단표**: 이름·구분·부서·연수마다 상태(이수일), 맨 아래 이수율, 그 아래 구분별 실적 표.
