# 혁신 기능 묶음 (2026-11-06) — 설계

선생님이 고른 것: A(결과지 맞춤 복습 문제) · C(AI 채점 정확도) · D(「쌤」 버튼 채팅) · 버튼 손그림 · E(아침 브리핑) · F(한 줄 관찰 메모) · K(다문화 가정통신문 번역) · L(업무 인수인계서).
선생님 답: A 정답은 **학생 칸 맨 아래 작게** · D는 **분명하면 바로 시작** · K는 **4개 언어(베트남어·중국어(간체)·러시아어·영어)** · F는 **행동특성 메모에 쌓기**.

## 공통 규칙

- 말투: 해요체, 짧게. 화면 글·알림·문서 모두.
- 개인정보: 학생 이름은 저장하지도 AI로 보내지도 않음. AI로 보내는 글은 `core/privacy.js`·`core/survey.js`의 `stripPersonal` 규칙을 따름(명단·전화번호 줄 빼기, 이름 가리기). 교직원 이름도 인수인계서·AI 입력에서 뺌.
- 서버 없음: 모든 자료는 브라우저 저장소(`core/store.js`, `ssam:` 키). 학년도별 자료면 `core/years.js` 규칙을 따름.
- AI: `core/ai.js`의 업무별 AI(`task`)를 씀. 새 업무 이름을 만들지 말고 가까운 것을 씀(복습 문제·번역·브리핑 요약은 `writing`/`notes` 중 맞는 것, 채팅 분류는 `notes`).
- 저장·결재·상신·나이스 저장은 언제나 선생님이 직접 누름.
- 연수 메뉴(`web/menus/training` 등)는 건드리지 않음(다른 선생님 영역).
- README·RELEASE_NOTES·버전 파일은 합치는 쪽에서 한 번에 고침(영역 작업에서는 고치지 않음).
- 시험: 순수 함수는 `tests/unit/*.test.mjs`, 화면은 `tests/e2e/*.mjs`(AI는 `tests/e2e/helpers.mjs`처럼 가짜로). 글꼴 패키지(fonts-nanum)는 설치하지 않음(단원평가 e2e 그림 위치가 바뀜).

## A. 단원평가 결과지 맞춤 복습 문제 (최대 3개)

- 자리: 평가 › 단원평가 4단계 「피드백」. [복습 문제 만들기] 단추 + 「결과지에 복습 문제 넣기」 스위치(만들면 켜짐) + 문항별 복습 문제 고치기 칸.
- AI는 평가 하나에 한 번: 틀리거나 부분 점수인 학생이 있는 문항마다 같은 개념의 비슷한 문제 1개와 정답·짧은 풀이(40자 안). 고르기 문항은 ①~④ 보기, 단답은 짧은 답, 서술형은 짧은 물음과 예시 답. 보내는 것: 문항 번호·평가 내용·영역·유형·정답·교과서 쪽뿐(학생 정보 없음). 결과는 그 평가에 저장.
- 학생마다: 틀린 문항·부분 점수 문항을 배점 큰 순(같으면 번호순)으로, 복습 문제가 있는 것만 **그 학생 칸에 남는 자리만큼 최대 3개**. 다 맞힌 학생은 넣지 않음.
- 남는 자리: 한 쪽에 2명이면 반 쪽, 번호별 한 장이면 한 쪽 기준으로 이미 쓴 줄(머리·점수·표 줄·잘한 점·한마디, 긴 글은 줄 수로 셈)을 빼고 남은 줄에 복습 문제(물음 줄 + 보기 줄 + 칸 1줄)를 넣을 수 있는 만큼. 이 셈은 순수 함수로 두고 시험함.
- 넣는 꼴: 한마디 아래 「다시 풀어 보기」 1) 2) 3), 그 학생 칸 **맨 아래에 작은 글씨로 「정답: 1) ② 2) 12.6 …」**. 인쇄·한글·워드·PDF·[모두 복사] 모두 같게(작은 글씨는 문서 내보내기에 작은 글 블록이 없으면 더함).

## C. AI 채점 정확도

- 단원평가·활동지: AI가 칸에 처음 매긴 점수(활동지는 ○△× 표시)를 칸마다 따로 기억(이미 있으면 덮지 않음). 선생님이 고치면 지금처럼 바뀐 값만 씀.
- 맞힌 칸 = 지금 값이 AI 처음 값과 같은 칸(노란 칸을 고치지 않고 확인만 한 것도 맞힘). 비율은 AI 처음 값이 있는 칸으로 셈.
- 보이는 곳: 채점·확인 단계 요약 줄, 결과 화면, 평가 목록. 꼴: 「AI가 맞힌 칸 97% (객관식 99% · 단답 96% · 서술형 88%) · 선생님이 고친 칸 7개」(활동지는 유형이 없으면 전체만). 채점을 마치기 전에는 「확인 중」.
- 누적: 단원평가 목록 위에 「올해 n개 평가 · AI가 맞힌 칸 평균 ○%」(활동지도 같은 꼴).
- 이 기능 전 채점한 평가: 「기록 없음」.

## D. 「쌤」 버튼 → 채팅 창 + 버튼 손그림

- 웹·앱 오른쪽 아래 「쌤」 버튼을 누르면 채팅 창(오른쪽 아래, 넓이 약 360, 닫기·Esc). 파일은 지금처럼 버튼이나 채팅 창에 끌어 놓으면 기존 받는 곳(`core/inbox.js`) 흐름 그대로. 채팅 창의 📎로 파일 고르기도.
- 글 분류: 먼저 앱 규칙(낱말)으로 고름(순수 함수 `routeText`, 시험함). 모르면 AI(`notes`)에 할 일 목록을 주고 하나 고르게(글은 개인정보 줄을 빼고). 그래도 애매하면 후보 버튼 2~3개.
- **분명하면 바로 시작**: 그 메뉴로 가서 칸을 채우고 시작. 예) 「알코올램프 10개 5,000원 품의」 → 품의 넣기 칸에 넣고 초안까지 / 「연수 안내 쪽지 …」 → 쪽지 쓰기 / 「가정통신문 …」 → 가정통신문 / 「공문 …」 → 공문 처리 / 「단원평가 채점」·「활동지」·「수행평가」 → 그 탭 / 「주간학습안내」 → 그 탭 / 「3번 …」 → F / 「브리핑」·「오늘 할 일」 → E / 「인수인계서」 → L / 「가정통신문 베트남어로」 → K / 「AI 키」 → 설정 › AI.
- 다른 영역이 주는 들어가는 곳(있을 때만 부름): 가정통신문 번역 `openLetterTranslate(lang)`(`web/menus/etc/letter.js`), 인수인계서 `openHandover()`(`web/menus/settings/handover.js`).
- 채팅 기록: 최근 30개만 저장, [지우기].
- Windows 바탕화면 「쌤」 버튼: 누르면 쌤비서 창이 열리고 채팅도 열림.
- 버튼 그림: 손으로 그린 듯 살짝 삐뚤한 원 + 손글씨 「쌤」(글꼴 파일 없이 SVG 경로로), 테마 색. 웹 버튼과 바탕화면 버튼 같은 그림(앱 아이콘은 그대로).

## E. 아침 브리핑

- 채팅을 열면 맨 위에 「오늘 할 일」(AI 없이 앱이 셈): 공문 제출 기한(지남·D-7 안), 학사일정(오늘~7일, 행사계획 날짜 포함), 채점·피드백이 덜 끝난 단원평가·활동지·평가지 채점, 금요일이면 다음 주 주간학습안내, 날짜가 14일 안인데 확정 안 한 행사계획. 줄을 누르면 그 화면으로. 없으면 「오늘은 급한 일이 없어요」.

## F. 한 줄 관찰 메모

- 채팅에 「3번 토론에서 근거 들어 반론 잘함」(「3·5번 …」처럼 여러 번호도) → 평가 › 행동특성의 그 번호 메모 끝에 「[11. 6.] 토론에서 근거 들어 반론 잘함」을 덧붙임(학생 줄이 없으면 만듦). 이름처럼 보이는 말은 가려서 저장. 채팅에 [되돌리기]. 「3번 메모 보기」는 그 메모를 채팅에 보여 줌.

## K. 다문화 가정통신문 번역 (베트남어·중국어(간체)·러시아어·영어)

- 기타 › 가정통신문에서 글을 만든 뒤 [번역본 만들기] → 언어 고르기 → AI가 제목·본문 문단·알림 앱용 짧은 글을 번역. 문서는 **원문과 나란히**(문단마다 한국어 뒤에 그 언어), 학교 양식(.hwpx)이면 그 양식 그대로, 아니면 기본 양식·워드·PDF. 언어별로 저장해 다시 부르지 않음.
- 전화번호·날짜·숫자만 있는 줄은 AI로 보내지 않고 그대로 둠. 「AI 번역이에요. 보내기 전에 확인해 주세요」 알림.
- `export function openLetterTranslate(lang)`: 가정통신문 탭으로 가서 그 언어 번역을 시작(글이 없으면 먼저 쓰라고 알림).

## L. 업무 인수인계서

- 자리: 설정 › 학년도에 [업무 인수인계서 만들기], 채팅 「인수인계서」. `export function openHandover()`.
- 모으는 것(지금 학년도): 연간계획(업무명·목표·월별 일정), 행사계획(행사명·날짜·상태·내년 개선 메모), 품의 최근 작성(제목·종류·금액·날짜), 공문 처리(제목·기한·할 일·완료), 결과 보고 목록. 학생 자료·명단·교직원 이름·전화번호는 넣지 않음.
- 문서: 1. 맡은 업무 한눈에(표) 2. 월별 할 일(3월~2월 표) 3. 행사와 개선 메모 4. 예산 집행(품의 표·합계) 5. 주요 공문·제출 6. 다음 담당자에게(선택: [AI로 정리]가 위 내용만 보고 3~6줄). 한글·워드·PDF로 내려받기(`core/doc-export.js`).
