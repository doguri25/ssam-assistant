# 「쌤」 채팅 → 마주온 톡톡 안내 (짧은 설계, 2026-11-18)

## 왜

「쌤」 채팅 AI는 학교 업무 일반 질문에도 동료처럼 답한다. 복무·수당·여비·휴가·징계·민원·교육청 정책 같은 **규정 질문**은
금액·날짜·조항을 그럴듯하게 지어낼 위험이 크고, 정확한 답은 교육청 AI인 **마주온 톡톡**이 맡는다(11. 15. 설계에서 정책·민원 에이전트는 쌤비서가 하지 않기로 함).

## 정한 것 (선생님 승인 2026-11-18 「톡톡은 좋아요」)

- 「쌤」 채팅에 규정 질문이 오면 답 **맨 위에** 안내를 붙인다(AI 없이, AI가 없어도):
  > 교육청 규정은 **마주온 톡톡**이 정확해요. 마주온(ai.cne.go.kr) 로그인 → 첫 화면 맨 아래 「마주온 톡톡」에서 물어보세요.
- 그 아래 AI 답은 일반 안내만 하고 금액·날짜·조항 번호는 지어 말하지 않는다(채팅 AI 공통 안내에 규칙 한 줄).
- 쌤비서 쓰는 법 질문(「품의 사유는 어떻게 써?」「강사 수당 품의 어떻게 해?」)은 지금처럼 — 안내를 붙이지 않는다.
- 해 달라는 말(분명한 명령, 규칙으로 고른 할 일)에는 붙이지 않는다.

## 어떻게 (만드는 사람 몫)

- 규정 질문 알아보기는 규칙으로(`web/core/chat-route.js`): 묻는 글(`isQuestion` 또는 얼마·몇·되나·가능·알려 줘) +
  규정 낱말(복무·연가·병가·조퇴·외출·육아시간·출장·여비·수당·호봉·봉급·성과급·초과근무·시간외·휴직·징계·규정·지침·법령·조례·훈령·민원·정책·맞춤형 복지·복지 포인트 등),
  쌤비서 기능 낱말(품의·평어·행특·가정통신문·쪽지·공문 처리·단원평가·활동지·쌤비서·메뉴·버튼·화면 …)이 있으면 아님.
- `chat.js`의 도우미 길(분명하지 않거나 묻는 글: AI·AI 없는 길 모두)에서 답보다 먼저 안내 한 줄.
- 안내에서 찾기(`chat-knowledge.js`)에도 「마주온 톡톡」 항목, README 「쌤」 채팅 줄에 한 문장.

## 접근 (고른 것)

- (고름) 규칙으로 알아보고 앱이 안내를 붙임: AI가 없어도, AI가 안내를 빼먹어도 늘 보임.
- (안 고름) AI에게만 「톡톡을 안내하라」고 시킴: AI가 없으면 안 되고 빼먹을 수 있음.
- (안 고름) 규정 질문은 AI에 보내지 않음: 일반 안내까지 막혀 선생님이 불편.
