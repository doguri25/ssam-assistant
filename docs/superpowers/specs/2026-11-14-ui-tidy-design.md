# 화면 정리(글·세부 메뉴 줄이기) — 설계 (2026-11-14)

선생님 요청: 「글과 세부 메뉴가 많아 한눈에 안 들어온다」 — 점검 뒤 추천한 1~4번을 모두 진행.
(1) 화면 오류 3가지, (2) 자주 안 바꾸는 설정 접기, (3) 단원평가 진행 표시 겹침 정리, (4) 설명 글 줄이기·「AI로 가는 것」 통일, 평가 탭 두 묶음·「기타」 이름 바꾸기.
아이콘: 왼쪽 메뉴·휴대폰 아래 탭에는 이미 있음 — 위 세부 탭에는 넣지 않음.

## 공통 규칙
- 기능·저장 자료는 바꾸지 않음(보이는 모양만). 해요체·짧게, 색만으로 뜻을 나르지 않음, 누르는 칸 44px, 390px에서 넘치지 않음.
- 기존 e2e가 찾는 단추·칸(id·data-*)은 그대로 두고, 접힌 안에 들어간 칸은 시험이 펼친 뒤 누르도록 시험을 고침(시험이 기능을 잃지 않게).
- 공통 부품 `web/core/ui-parts.js`(평가 메뉴 옛 화면은 `window.SSAM.ui`, 준비되면 `ssam:ui-ready` 알림):
  - `introHTML(key, text)` — 머리말 아래 설명(한두 문장). 처음 3번(앱을 켤 때마다 화면마다 한 번 셈)은 펼침, 그 뒤엔 접힌 「화면 설명」. 셈은 공통 키 `ui:intro`(학년도 자료 아님).
  - `aiNoteHTML(text)` — 「AI로 가는 것」(자물쇠 그림 + 글). 접혀 있고 펼치면 무엇을 보내는지 + [AI로 보낸 글 보기](설정 › AI 카드로).
  - `foldHTML({ key, summary, body, open })` — 설정 요약 한 줄 + [바꾸기], 펼치면 설정 칸. 다시 그려도 펼친 채로.
  - CSS는 `web/core/shell.css` 끝(`.intro`·`.ai-note`·`.fold`).

## 1. 화면 오류
- 설정 › AI 「기본 검토 AI」 선택 칸이 위아래로 크게 늘어남(약 170px) → 다른 선택 칸과 같은 높이.
- 오른쪽 아래 「쌤」 단추(웹 떠 있는 버튼)가 화면 끝 단추를 가림(예: 학급 › 기초학력 [+ 학생]) → 모든 메뉴 화면 끝에 단추만큼 여백(데스크톱·휴대폰, 옛 평가 화면 포함), 오른쪽 끝 단추가 가려지지 않게.
- 휴대폰 단원평가: 한 바퀴 띠 + 1~4단계가 첫 화면 절반 → 3번에서 해결.

## 2. 자주 안 바꾸는 설정 접기 (`foldHTML`)
- 평가 › 행동특성: 맨 위 분량 기준·분량·후보·문장 끝·학생 수·예외 번호·학년 → 「300~500자 · 후보 2개 · ~함. · 3학년 12명」 요약 한 줄. 학생 수가 비어 있으면 펼친 채로.
- 행특 특성 단추(57개): 묶음(생활·학습·관계·특기·성장 중)마다 접기, 처음엔 첫 묶음만 펼침. 고른 특성 수를 묶음 머리에 「생활 · 2개 골랐어요」.
- 평가지 채점·교과 평어·창체의 설정 줄(분량·문장 끝·평가 방식 등)도 같은 방식. 단원평가·활동지의 설정 줄이 있으면 같은 방식.
- 각 화면의 AI 줄(「AI: … · 검토 끔 바꾸기」)은 그대로(한 줄이라 접지 않음).

## 3. 단원평가 진행 표시
- 한 바퀴 띠를 기본은 한 줄 요약으로: 「평가 한 바퀴 2/6 · 다음: 틀린 까닭 ▸」(지금 마디 이름) — 누르면 지금처럼 6마디가 펼쳐짐(펼침은 이 실행 동안 기억, 다 끝났으면 「평가 한 바퀴 6/6 ✓」).
- 1~4단계 탭은 그대로. 휴대폰에서 단계 탭은 한 줄로 밀어 넘김(두 줄로 감싸지 않음).

## 4. 설명 글 줄이기 · 「AI로 가는 것」 · 메뉴 묶음
- 화면마다 머리말 설명을 `introHTML`로(글은 한 줄 48자 안팎으로 다듬음). 머리말 제목은 그대로.
- 버튼 줄 아래 「AI에는 …만 보내요. 이름은 보내지 않아요」 같은 회색 글을 `aiNoteHTML`로 바꿈(뜻은 그대로, 사실과 맞게). 그 밖의 쓰는 법 회색 글은 꼭 필요한 것만 남기고 줄임(빈 화면 안내·오류·확인할 것 알림은 그대로).
- 평가 탭 두 묶음: 「채점」 단원평가·활동지·평가지 채점 | 「생활기록부」 교과 평어·창의적 체험활동·행동특성·기재 점검. 탭 줄 안에 묶음 이름(작은 글)과 구분선. 탭 id·마지막 탭 기억은 그대로.
- 「기타」 → 「문서·소통」(왼쪽 메뉴·더보기·채팅 안내·둘러보기 글·README). 메뉴 id(`etc`)는 그대로.
