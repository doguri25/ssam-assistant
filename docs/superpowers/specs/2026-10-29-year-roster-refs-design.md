# 학년도·명단 엑셀·행사 참고 자료 설계

- 날짜: 2026-10-29
- 요청(선생님): ① 설정의 학생 명단을 엑셀로도 넣기 ② 학년도가 끝나면 저장하고 새 학년도로 넘어가기 ③ 행사계획에 상위 계획·교육청 공문 등을 넣는 칸을 두고 참고하기 ④ 연수·품의를 빼고 계속 만들기
- 결정(2026-10-29 질의)
  - 명단 엑셀: **번호만** 가져온다(학생 수·예외 번호). 이름은 읽기만 하고 저장하지 않는다.
  - 학년도: **백업 파일 만들기·불러오기**와 **앱 안에서 학년도 오가기**를 둘 다 만든다.

## 1. 학급 명단 엑셀 (설정 › 학급 명단)

- [엑셀·CSV에서 가져오기] 버튼을 명단 카드에 둔다. `.xlsx`·`.csv`(`core/sheet.js`의 `readTable`). `.xls`는 「엑셀에서 .xlsx로 다시 저장해 주세요」.
- 읽는 규칙(나이스 학생 명렬표 등):
  - 첫 몇 줄 안에서 「번호」가 든 칸을 머리 칸으로 잡는다. 그 열의 1~60 정수가 학생 번호.
  - 「학적」「변동」「비고」「상태」가 든 머리 칸이 있으면, 그 칸에 「전출·전학·자퇴·제적·면제·유예」가 있는 번호는 예외 번호.
  - 학생 수 = 가장 큰 번호. 1~학생 수 사이에 없는 번호도 예외 번호.
  - 번호 열을 못 찾으면 「번호 칸을 찾지 못했어요. 첫 줄에 「번호」가 있는 명렬표인지 확인해 주세요」.
- 넣기 전에 미리 보기 시트: 「학생 25명 · 예외 번호 7, 20」 + [넣기]. 이름·생년월일 등 다른 칸은 저장하지도, AI에 보내지도 않는다.
- 넣으면 평가 메뉴의 명단(`ssam:class`)이 바뀌고 창체·행특·채점이 함께 쓴다(기존 `setClass`).

## 2. 학년도 (설정 › 학년도, 새 탭)

### 2.1 무엇이 학년도마다 따로인가
- **공통(학년도와 상관없음)**: AI 키·모델(`engine`), 화면 테마(`theme`), 메뉴 위치(`nav`), 평가 화면 종류(`mode`), 업데이트 건너뛰기(`updSkip`), 옮기기 표시(`mig:*`), 학년도 목록(`years`).
- **학년도마다 따로**: 그 밖의 모든 `ssam:` 자료 — 학교 정보, 학급 명단, 평가(평가계획·평어·창체·행특·채점), 학급(시간표·진도표·체크·주간학습안내), 학사일정, 연간계획, 행사계획, 품의.
- 지금 학년도의 자료는 지금처럼 `ssam:` 키에 그대로 둔다(기존 화면 코드는 바꾸지 않음). 다른 학년도는 **보관함**(IndexedDB `ssam-archive`)에 학년도별 묶음으로 둔다.
- 학년도 목록 `ssam:years = { current: 2026, saved: [2025] }`. 처음에는 오늘이 든 학년도(3월~다음 해 2월).
- 설정 › 학교 정보의 「학년도」는 연간계획·행사계획을 세우는 학년도라서 이름을 「계획 학년도」로 바꾸고 「연간계획을 세울 학년도예요. 10월부터는 다음 학년도로 잡혀요」라고 안내한다.
- 왼쪽 세로 메뉴의 「사용 중인 AI」 위에 「2026학년도」를 보이고, 누르면 설정 › 학년도로 간다.

### 2.2 화면 (설정 › 학년도)
- **지금 학년도**: 「2026학년도」, 자료 크기.
- **백업**: [백업 파일 만들기] → `쌤비서 백업 2026-10-29.json` 내려받기(지금 학년도 + 보관한 학년도 모두). **AI 키는 넣지 않는다.** [백업 파일 불러오기] → 파일 속 학년도 목록을 보이고 고른 것만 불러온다.
  - 지금 학년도와 같은 학년도 → 지금 자료를 파일 내용으로 바꿈(확인 창).
  - 다른 학년도 → 보관함에 넣음(이미 있으면 바꿈, 확인 창).
- **학년도 목록**: 학년도마다 「지금」 또는 「보관됨 · 저장한 날」, [이 학년도로 가기], [지우기](보관한 것만, 확인 창: 「먼저 백업 파일을 만들어 두세요」).
- **새 학년도 시작**: [2027학년도 시작하기] → 확인 창
  - 「2026학년도 자료는 보관함에 그대로 남고, 언제든 돌아올 수 있어요. 백업 파일도 만들어 두면 좋아요」 + [백업 파일 만들기].
  - 새 학년도에 **가져가는 것**: 연간계획·행사계획(내년 계획의 작년 자료로), 학사일정 중 새 학년도(3월 1일부터) 날짜, 학교명·학급 수·학생 수(계획 학년도와 방학은 비움).
  - **비우는 것**: 학급 명단, 평가 자료, 학급 메뉴 자료, 품의 작성 중인 것.
  - 이미 보관함에 그 학년도가 있으면 「2027학년도 자료가 이미 있어요. 그 학년도로 가기」로 바꿔 보인다.
- 학년도를 옮기면(가기·새로 시작·지금 학년도 불러오기) 앱을 다시 연다(화면 새로 고침).

### 2.3 옮기는 순서 (자료를 잃지 않게)
1. 쓰기 멈춤: 모든 저장을 멈춘다(평가 메뉴의 `S.wiping`, `core/store.js`의 멈춤).
2. 지금 학년도 자료를 보관함에 쓴다(끝날 때까지 기다림). 실패하면 멈춘 것을 풀고 「보관하지 못했어요. 지금 자료는 그대로예요」로 끝.
3. 가려는 학년도 자료(보관함 또는 새 학년도 가져가기 묶음)를 준비한다.
4. 학년도마다 따로인 키를 모두 지우고 준비한 자료를 쓴다. `ssam:years`를 고친다.
5. 다시 연다.
- 앱 안에 보관한 자료는 그 컴퓨터의 브라우저 저장소에만 있다. 화면에 「컴퓨터를 바꾸거나 프로그램을 지우면 사라져요. 백업 파일을 만들어 두세요」를 둔다.

### 2.4 백업 파일 모양
```json
{ "app": "ssam", "kind": "backup", "version": 1, "createdAt": "2026-10-29T09:00:00.000Z", "current": 2026,
  "years": { "2026": { "class:info": "<저장된 글 그대로>", "…": "…" }, "2025": { "…": "…" } } }
```
- 값은 `localStorage`에 저장된 글을 그대로(다시 JSON으로 풀지 않음). 공통 키와 AI 키는 넣지 않는다.
- 읽을 때 `app`·`kind`·`version`·`years` 모양이 틀리면 「쌤비서 백업 파일이 아니에요」.

## 3. 행사계획 참고 자료 (계획 › 행사계획 1단계)

- 1단계에 카드 「참고 자료 (선택 · 상위 계획, 교육청 공문 등)」를 둔다.
  - [연간계획에서 불러오기]: 저장한 연간계획 목록에서 골라 그 계획의 글(`planText`)을 「상위 계획」으로 넣는다.
  - [파일 넣기]: 한글·PDF·엑셀·CSV 여러 개. 이름은 파일 이름, 종류는 파일 이름에 「공문·교육청·교육지원청·교육부」가 있으면 「교육청 공문」, 「계획」이 있으면 「상위 계획」, 아니면 「기타」.
  - [붙여넣기]: 시트에서 종류·이름·글을 넣는다.
  - 목록: 종류(상위 계획·교육청 공문·기타), 이름, 글자 수, [보기·고치기], [빼기].
- 저장: 행사마다 `refs: [{ id, kind: 'upper'|'official'|'other', name, text }]`, 글은 모두 합쳐 60,000자까지(넘으면 앞부분만, 알림). 원본 파일은 저장하지 않는다.
- AI(구성안·문서)에 참고 자료를 함께 보낸다. 자료가 여러 개면 합쳐 24,000자 안에서 고르게 줄인다.
  - 규칙: 「참고 자료의 요구 사항(날짜·대상·필수 활동·안전 기준·제출할 것 등)을 지키고, 반영한 것을 refNotes에 짧게 쓴다. 참고 자료에 없는 사실은 지어내지 않는다」.
  - 받은 `refNotes`를 2단계(구성안)·3단계(문서) 위에 「참고 자료에서 반영한 것」으로 보인다.
- 확정한 행사의 참고 자료를 고치면 다른 정보처럼 「작성 중」으로 돌아간다.

## 4. 다듬기 (연수·품의 제외)

- 학급(지난 검토의 미룬 것 중 쓰는 사람에게 보이는 것):
  - 오늘 수업 차시를 진도표의 단원 안 차시(「5/14차시」)로. 진도표 파일의 차시 칸을 저장하고, 없으면(AI·직접) 단원이 이어지는 줄로 센다.
  - 교시 수를 줄였다가 늘려도 칸이 남는다(7교시까지 늘 저장, 보이는 줄만 바꿈).
  - 주간학습안내 학사일정 칸을 비울 수 있다(비운 것도 「고친 것」으로 저장).
  - 예시 자료는 오늘이 든 학년도의 2학기(8월 마지막 월요일부터)로 만든다.
- 문서: README를 심사용으로(무엇을 하는 앱인지, 웹·Windows로 써 보기, 샘플 파일로 시연하는 순서, 개인정보), PRD에 학급(동작)·학년도·명단 엑셀·행사 참고 자료를 반영.

## 5. 시험

- Node: 명단 엑셀 읽기(번호 열·학적 열·빈 번호·머리 줄 위치), 학년도 키 나누기, 백업 만들기·읽기(공통 키·AI 키 빠짐, 모양 검사), 새 학년도 가져가기 묶음(학사일정 날짜 거르기, 학교 정보), 학년도 옮기기 순서(보관 실패면 아무것도 안 바뀜), 행사 refs 정규화·글자 수 제한·프롬프트 나누기, 학급 단원 차시.
- Playwright: 명단 엑셀 → 미리 보기 → 넣기 → 평가 명단 바뀜. 학년도: 예시 자료 → 백업 파일(AI 키 없음) → 새 학년도 시작 → 학급 비고 연간계획 남음·옆 메뉴 「2027학년도」 → 2026으로 돌아가기 → 학급 자료 돌아옴 → 보관 지우기 → 백업 불러오기. 행사 참고 자료: 붙여넣기·파일·연간계획에서 → 구성안 프롬프트에 들어감 → 「참고 자료에서 반영한 것」 보임, AI가 도는 동안 다른 행사로 가도 섞이지 않음.
- 사람 확인: Windows 앱에서 백업 파일이 다운로드 폴더에 저장되는지, 학년도를 오간 뒤 평가 메뉴 자료가 맞는지.

## 6. 범위 밖
