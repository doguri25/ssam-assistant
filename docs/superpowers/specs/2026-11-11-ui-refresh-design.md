# 화면 개선 4가지 — 설계 (2026-11-11)

ui-ux 점검 뒤 선생님이 고른 목업(캔버스 「쌤비서 화면 개선 목업」 A~D)을 앱에 넣음.
선생님 답: 앱을 켜면 **「오늘」부터** · 휴대폰 아래 탭은 **오늘·평가·학급·품의·더보기**(계획·연수·기타·설정은 더보기 안).

## 공통 규칙
- 화면만 바꿈: 저장 모양·기능·AI로 보내는 글은 그대로. 연수 메뉴 안쪽은 고치지 않음(메뉴 자리만 옮김).
- 색은 테마 토큰(`var(--accent)`, `--accent-soft`, `--ink*`, `--line`, `--surface*`, `--ok`, `--warn`, `--err` …)만 — 테마 5가지 모두에서 보이게. 글 대비 4.5:1, 누르는 칸 44px 이상, 키보드 초점 보임, `prefers-reduced-motion`.
- 색만으로 뜻을 나르지 않음(○·/·✓·「입력 필요」 같은 글·기호를 함께). 해요체·짧게.
- 390px에서 가로로 넘치지 않음.

## 1. 셸 (web/core/shell.js·shell.css·icons.js·index.html)
- 메뉴 맨 위에 **오늘**(`home`, 탭 없음). 머리 제목 「오늘」.
- **앱을 켜면(열기·새로 고침) 늘 오늘**. 메뉴마다 마지막 탭 기억(`nav:tabs`)은 그대로, 마지막 메뉴(`nav`)는 저장만 하고 시작할 때 쓰지 않음. 다른 곳에서 부르는 `go(menu, tab)`(채팅·쌤 버튼·카드 링크)는 그대로.
- **휴대폰(≤760px)**: 왼쪽 메뉴 → 아래 탭 5칸(오늘·평가·학급·품의·더보기, 아이콘+글, 칸 높이 52px 이상, 아래 안전 영역 여백). 더보기 → 시트(계획·연수·기타·설정, 학년도·사용 중인 AI). 지금 메뉴가 더보기 안 것이면 더보기 칸이 켜짐(`aria-current`). 가로 탭(#menuTabs)은 한 줄 가로 스크롤 칩. 내용 아래 여백 = 아래 탭 + 쌤 버튼.
- **쌤 떠 있는 버튼·알림(toast)**: 휴대폰에서는 아래 탭 위로. 데스크톱은 자리 그대로, 내용 끝에 여백(버튼이 마지막 글을 가리지 않게).

## 2. 오늘 화면 (web/menus/home/ — home.js 화면, home-model.js 순수 함수 + Node 시험)
- 머리: 「11월 11일 수요일 · 2026학년도」, 「오늘 챙길 일 n가지」(n = 아래 카드의 할 일 수, 없으면 「오늘은 급한 일이 없어요」), 사용 중인 AI 칩(준비됨/정해 주세요 → 설정 › AI).
- **파일 놓는 칸**: 「무엇이든 여기에 놓으세요」 — 끌어 놓기·[파일 고르기] → `core/inbox.js receive(files)`(쌤 버튼과 같은 길). 화면의 주 버튼은 이것 하나.
- **카드 3개**(넓으면 3칸, 좁으면 아래로):
  - 공문 기한: 지남·오늘·D-n(7일 안, 다 한 것 빼고) 3개까지, 기호+색 배지, [공문 처리] 링크. 없으면 「가까운 기한이 없어요」.
  - 오늘 수업: 학급 › 오늘 수업 자료의 교시마다 교과·차시·상태(완료·일부·못 함·남음), 지금 시각의 교시 강조(「지금」). 없으면 「진도표·시간표를 넣으면 보여요」 + 링크.
  - 교과캠프 출석: 오늘 수업이 있는 캠프(여럿이면 지금 고른 캠프 먼저): 학생마다 큰 버튼 — 누르면 그날 수업 모두 ○ → / → 빈칸, [모두 출석](camp-model `markAll`), [캠프 열기]. 오늘 캠프 수업이 없으면 카드를 숨김(다른 두 카드가 넓어짐).
- **이어서 하기**(5줄까지): `core/briefing.js`의 줄(행사·학사일정·단원평가·활동지·평가지 채점·주간학습안내) + 품의 최근 초안 + 다면평가(정량 총점 n/100 · 입력 필요 n곳, 시작한 경우만) — 줄마다 누르면 그 화면으로.
- 다 비었으면(처음 쓰는 선생님) 시작 안내 3단계: AI 정하기 · 학급 명단 넣기 · 파일 놓기.
- 채팅 「오늘 할 일」「브리핑」은 지금처럼 채팅 위 목록 — 줄 맨 위 [오늘 화면 열기]만 더함.

## 3. 기초학력 캠프 (web/menus/class/camp.js·camp.css)
- 둥근 섹션 탭 → **단계 진행 표시** 6칸: 번호·이름 + 상태 한 줄(「대상 3학년 · 국어·수학」·「55줄 · 총 55시간」·「12 / 55 수업 체크」·「입력 필요 2명」·「아직 안 씀 / n칸」·「2 / 4 준비됨」), 다 된 단계 ✓, 지금 단계는 진한 칸(`aria-current="step"`). 좁으면 가로 스크롤.
- **출석 칸**: 64×48 이상. ○ 출석(진한 채움)·/ 결석(주황 테두리·연한 바탕·굵게)·— 체크 안 함(점선). 날짜 고르기는 가로 칩(다 체크한 날 ✓). [남은 칸 모두 출석].
- **문서 준비** 상자(출석 체크 옆, 좁으면 아래): 문서 4종 — 준비됨(초록 점)·할 일 남음(주황 점, 「출석 43줄 남음」「관찰 글 2명」)·아직(빈 원) + 그 단계로 가는 링크.

## 4. 다면평가 정량 (web/menus/etc/multi.js·multi.css)
- **점수 요약 줄을 위에 고정**(sticky): 총점 큰 글씨 「63 / 100점」, 묶음마다 소계 막대(소계가 묶음 최대의 절반 미만이면 주황), 「입력 필요 n곳」(누르면 첫 빈 항목으로 스크롤·초점), [한글로 내려받기].
- **항목 카드**: 고른 지표는 ✓ 칩, 나머지 지표는 회색 칩(범위 항목은 숫자 칸 옆에 어느 구간인지 바로 보임), 횟수 항목은 [−] n회 [+] 버튼과 「3회 × 1점 = 3점 → 최대 2점」, 값이 빈 항목은 주황 테두리 + 「입력 필요」.
- **근거자료**: 칩(「제목 [번호, 날짜.]」 + ×) + [+ 근거자료].

## 시험
- 단위: home-model(카드 자료·할 일 수·지금 교시·캠프 오늘 수업·이어서 하기 줄), 캠프 단계 상태, 다면평가 입력 필요 수.
- 화면(e2e): 켜면 오늘·카드·파일 놓기·카드 링크·캠프 오늘 출석 누르기 / 390px 아래 탭 5칸·더보기 시트·가로 넘침 없음·쌤 버튼이 아래 탭과 겹치지 않음 / 캠프 단계 표시·큰 출석 칸 / 다면평가 고정 요약·입력 필요로 가기 / 다른 화면 시험은 시작 화면이 바뀐 만큼만 고침.
