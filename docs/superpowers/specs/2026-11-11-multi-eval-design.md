# 기타 › 다면평가 — 설계 (2026-11-11)

선생님 요청: 기타에 **다면평가 작성**. ① 정성평가·정량평가 두 가지 ② 학교마다 양식·기준이 다르니 **기준 양식 넣는 칸** ③ 정량은 항목마다 **숫자를 넣으면 자동 계산**, **근거자료 넣는 칸** ④ 정성은 **줄글로 쓰면 알아서 넣고**, 입력이 필요한 곳은 **「입력 필요」 표시 후 추가 입력**.
선생님 답: 근거자료는 **파일 넣기 + 비고 자동**(항목마다 공문·이수증 PDF·사진·한글 파일을 이 기기에 보관하고 「문서 제목 [번호, 날짜.]」를 비고 칸에, AI가 있으면 AI가, 없으면 글에서 찾고 그래도 없으면 파일 이름. 글로 고칠 수 있음) · 결과는 **양식 모양대로 새 파일**(넣은 학교 기준의 항목·칸 그대로 한글·워드·PDF로 새로 만듦 — .hwp 양식도 됨).

참고 양식(선생님이 보낸 .hwp 2개, 저장소에 넣지 않음. 시험·예시에는 지어낸 학교 「새싹초등학교」·지어낸 이름만):
- **정량평가 기준**: 제목 「2025학년도 교사 다면평가 기준(정량평가)」, 「평가 기간 : 2025. 3. 1. ~ 2026. 2. 28.」, 표 `구분 | 평가 사항 | 평가요소 | 평가지표 | 배점 | 확인 ( ○ ) | 점수 | 소계 | 비고(실적 증빙자료)`.
  평가요소 묶음 `가. 학습지도 (30점)`·`나. 생활지도 (30점)`·`다. 전문성계발 (10점)`·`라. 담당업무 (30점)` 아래 항목 `주당 수업시수 (25점)` 등, 항목마다 지표 줄 `•22시간 이상 | 25점`, `•20시간 이상 ~ 22시간 미만 | 24점`, `•20시간 미만 | 23점`. 다른 꼴: `•동료장학 수업 유/무`(고르기), `•자발적 수업 공개 (컨설팅 의뢰, 회당 1점) | 2점 | 회`(횟수 × 1점, 최대 2점), `•통합학급, 비교과 (6개월 이하 4.5점) | 5점`(근무 6개월 이하면 다른 점수), `•75시간～89시간 | 6점`. 비고 칸에 증빙 안내(「나이스 출력(상담기록)」)·감점 규칙(「수업일 휴직 기간은 월 0.2씩 감점」).
  끝 줄 `총 계 | 100점 | (     )점`, 안내 `※ 동점자 처리 기준 : …`, `상기 내용이 틀림없음을 확인하여 제출합니다.`, 날짜, `작성자 : 교사 (서명)`, `○○초등학교 다면평가관리위원장 귀하`, 확인 칸 `1차 | 2차 | 최종`. 같은 파일에 작성 예시(확인 ○·점수·소계·비고 `• 학교 교육과정(수정) [9959, 2025.07.22.]`·총계 `( 90 )점`)가 이어짐 → 기준은 **첫 표만** 읽음.
- **정성평가 기준 + 교사 자기실적평가서**: 표 `구분 | 평가사항 | 평가요소 | 평가지표`(1. 근무수행태도 › 교육공무원으로서의 태도 (10점) › 1) … 2) …, 2. 근무실적 및 근무수행능력 › 가. 학습지도(40점) · 나. 생활지도(30점) · 다. 전문성개발(5점) · 라. 담당업무(15점) › 지표 질문들).
  이어서 「교육공무원 승진 규정 【별지 제3호의2 서식】 교사 자기실적평가서」: 1. 평가 지침 / 2. 평가 기간 / 3. 평가자 인적사항(○ 소속 ○ 직위 ○ 성명) / 4. 평가자 기초 자료(○ 담당 학년 및 학급 ○ 담당 과목 ○ 담임 여부 ○ 담당 업무 ○ 보직교사 여부 ○ 주당 수업시간 수 ○ 연간 수업공개 실적 ○ 연간 학생 상담 실적 ○ 연간 학부모 상담 실적 ○ 그 밖의 실적사항) / 5. 자기실적 평가(가. 학습지도 나. 생활지도 다. 전문성개발 라. 담당 업무 — 각각 ◦ 추진 목표 - … ◦ 추진 실적 - …, 담당 업무는 ◦ 창의적 업무개선 사항도) / ※ 자기 평가 종합 상황(목표달성도·창의성·적시성·노력도 × 만족·보통·미흡 ○표) / 작성일 · 작성자(본인) 성명 서명(인) / ◇ 확인자(직근상급자) : 직위 성명 서명(인).

## 공통 규칙
- 해요체·짧게. 저장·결재·제출은 선생님이. 연수 메뉴·README·RELEASE_NOTES·버전 파일은 영역 작업에서 고치지 않음(합칠 때 따로).
- 선생님 이름·학교 이름은 **AI로 보내지 않음**(문서에만). 줄글·근거자료 글을 AI로 보낼 때 `core/chat-names.js maskPersons`로 사람 이름 모양을 가림. 사진 근거자료는 AI가 있을 때만 그림으로 보냄(가릴 수 없음 — 넣는 칸에 「학생 이름이 보이는 자료는 넣지 마세요」 안내).
- AI는 `core/ai.js`의 기존 업무만: 기준 양식 읽기·근거자료 제목 읽기 = `plan`, 줄글 나누기 = `writing`. `core/shell.js SSAM_WORK`가 기타 › 다면평가에서 부른 `plan`·`writing`을 기타 메뉴로 표시하게 고침(인수인계서·캠프와 같은 꼴).
- **AI가 없어도 다 됨**: 기준 양식은 규칙으로 읽고(못 읽으면 예시 기준 + 안내), 근거자료 비고는 글에서 찾고, 줄글은 낱말로 나눔.
- 문서 내보내기: `core/doc-export.js exportDoc`(한글·워드·PDF, 표 `widths` 비율 씀). 합친 칸 없는 단순 표.

## 저장
- 학년도 키 `multi`(core/years.js 규칙 — 공통 키가 아니어서 학년도·백업을 따라감).
- 넣은 기준 양식 원본·근거자료 파일: `core/form-store.js forms('multi')`(다른 메뉴 양식과 따로). 근거자료 파일은 백업 파일에 넣지 않음(크기) — 화면에 「근거자료 파일은 이 기기에만 있어요」.

```
multi = {
  info: { school, position: '교사', name, gradeClass, subject, homeroom, duty, head, from, to, short: false },   // short: 근무 6개월 이하
  quant: { criteria, formId, formName, values: { [itemId]: { v, count, deduct } }, evidence: { [itemId]: [{ id, fileId, name, label }] }, notes: { [itemId]: '' }, notesEdited: { [itemId]: true } },
  qual:  { criteria, formId, formName, draft, report, filled: { [path]: true } }
}
```

## 정량 (`multi-quant.js` 순수 함수 — 화면 없음, Node 시험)
기준 모양:
```
criteria = { title, period, total: 100, groups: [{ id, name: '가. 학습지도', max: 30, items: [
  { id, name: '주당 수업시수', max: 25, kind: 'range'|'choice'|'count', unit: '시간', guide: '증빙 안내(비고 칸 글)',
    tiers: [{ label: '22시간 이상', min: 22, minInc: true, max: null, maxInc: false, points: 25, short: null }],   // range
    // choice: tiers의 min/max 없음 — 하나 고름 · count: { per: 1 } 와 tiers[0].points = 최대
    deduct: null | { per: 0.2, unit: '개월', label: '수업일 휴직 기간' } }] }],
  notes: ['※ 동점자 처리 기준 : …'], footer: { pledge, to: '…위원장 귀하', checks: ['1차', '2차', '최종'] } }
```
- `parseQuantText(text) → criteria | null`: 한글·PDF·워드 글(`core/files.js readText` — 표 칸은 ` | `, 줄은 줄바꿈)에서 규칙으로. 묶음 `/^[가-하]\.\s*.+\(\s*(\d+(?:\.\d+)?)\s*점\s*\)/`, 항목 `이름 (n점)`, 지표 `•…` 다음 칸 `n점`, 지표 글에서 범위(`n시간 이상`·`n 미만`·`n～m시간`·`n~m`·`n건 이상`), `회당 n점`(count), `(6개월 이하 n점)`(short), 고르기(나머지). 비고 칸 글은 guide, `월 n씩 감점` → deduct. 두 번째 `총 계` 줄(작성 예시)부터는 버림. 묶음 1개·항목 2개 미만이면 null.
- `DEFAULT_QUANT`: 예시 기준(위 양식과 같은 항목 꼴, 학교 이름 없음, 제목 「교사 다면평가 기준(정량평가) — 예시」). 학교 기준을 넣기 전까지 씀(화면에 「예시 기준이에요. 학교 기준 양식을 넣어 주세요」).
- `tierOf(item, value, short)` · `itemScore(item, entry, short)`: range는 값이 든 지표의 점수(같으면 위 지표 먼저, short 점수가 있고 short면 그것), choice는 고른 지표, count는 min(횟수 × per, 최대), 감점은 빼고 0 아래로는 안 내려감, 값이 없으면 null(빈칸). `groupScore`(최대를 넘지 않음) · `totalScore`.
- AI(있으면, 규칙이 null이거나 PDF 스캔·사진일 때): 같은 모양 JSON(`multi-ai.js quantPrompt`·`normQuant`). 둘 다 못 하면 예시 기준 그대로 + 「기준 양식을 읽지 못했어요 …」.
- 화면에서 **기준 고치기**(접힘): 항목 이름·배점·지표 글·점수 고치기, 지표·항목 더하기/빼기(작은 표 편집). 고친 기준은 그대로 저장.

## 근거자료 (`multi-evidence.js`)
- 항목마다 [근거자료 넣기](여러 개, .pdf·.hwp·.hwpx·.docx·사진, 5MB까지) → `forms('multi')`에 보관(id·name·bytes·type), 칸에 파일 이름 + 「비고」 글(지우기 ✕, 글 고치기).
- `evidenceLabel(text, fileName) → { title, no, date, label }`(규칙): 공문 글의 `제목` 줄, 문서 번호(`○○학교-1234`·`[1234,`·`제1234호`), 날짜(`시행 … 2025. 7. 22.`·`2025.07.22.`) → `「제목 [1234, 2025.07.22.]」`, 모자라면 있는 것만, 아무것도 없으면 파일 이름(확장자 뺌).
- AI가 있으면 글(가린 것)·사진을 `plan`으로 보내 { title, no, date } — 규칙 결과가 제목·번호·날짜를 다 갖추면 AI를 부르지 않음.
- 항목 비고 칸 = 근거자료 label을 `• ` 붙여 줄마다(선생님이 고친 비고는 다시 쓰지 않음).

## 정성 (`multi-qual.js` 순수 함수 + `multi-ai.js`)
- 기준: `parseQualText(text) → { criteria: [{ area, element, max, indicators: [] }], basics: [필드 이름…], sections: [{ key, name, parts: ['추진 목표','추진 실적', …] }] }` — 「평가사항/평가요소/평가지표」 표와 「자기실적평가서」 글(○ 필드：, 가.~라. 영역, ◦ 추진 목표 …)에서. 못 읽은 부분은 `DEFAULT_QUAL`(위 별지 서식 꼴: 기초 자료 10칸, 영역 4개, 담당 업무에 창의적 업무개선 사항, 자기 평가 종합 4줄)로 채움.
- 보고서 모양: `report = { basics: { [필드]: 값|'' }, sections: [{ key, name, parts: [{ name, items: ['…'] }] }], self: { 목표달성도|창의성|적시성|노력도: '만족'|'보통'|'미흡'|'' }, missing: [{ path, label, hint }] }`.
- **줄글 → 칸**: [AI로 넣기](`writing`): 기준 지표·영역·칸 이름 + 가린 줄글 + 정량에서 아는 수(주당 수업시간 수·수업 공개·상담 건수·연수 시간·보직)를 보내고 위 JSON을 받음. 규칙: 쓴 사실만(지어내지 않음), 개조식(`- …`), 모르는 칸은 '' + missing에 「무엇을 적어야 하는지」 hint. AI가 없으면 [넣기]가 규칙으로 나눔(문장마다 낱말: 수업·학습·교과·코스웨어 → 학습지도, 상담·생활·학교폭력·인성·안전 → 생활지도, 연수·자격·연구회·공동체 → 전문성개발, 업무·부장·담당·운영 → 담당 업무; 목표/계획 말이 있으면 추진 목표, 나머지 추진 실적).
- 기초 자료는 내 정보·정량 값에서 먼저 채움(담당 학년 및 학급·담당 과목·담임 여부·담당 업무·보직교사 여부·주당 수업시간 수·수업 공개·상담). 빈 칸은 모두 missing.
- **입력 필요**: 맨 위 「입력 필요 n곳」 띠 + 칸마다 빨간 「입력 필요」 표시와 입력 칸. 적으면 그 칸에 바로 들어가고 표시가 사라짐. 자기 평가 종합은 만족·보통·미흡 고르기(안 고르면 입력 필요). 영역 글은 줄마다 고치기·더하기·지우기.
- 다시 [AI로 넣기]를 누르면 선생님이 고친 칸(filled)은 덮을지 물음.

## 문서 (`multi-docs.js`) — 양식 모양대로 새 파일
- 정량: 제목(기준 제목, 학년도), 「평가 기간 : …」, 표 `평가요소 | 평가지표 | 배점 | 확인(○) | 점수 | 소계 | 비고(실적 증빙자료)`(지표마다 한 줄, 항목 이름·점수·소계·비고는 그 항목 첫 줄에만, 고른 지표에 ○, count는 「n회」), 끝 줄 `총 계 | | 100점 | | ( n )점`, 안내 글, 「상기 내용이 틀림없음을 확인하여 제출합니다.」, 날짜, 「작성자 : 교사 성명 (서명)」, 「… 귀하」, 확인 표 `1차 | 2차 | 최종`.
- 정성: 「교사 자기실적평가서」(별지 서식 꼴) — 1~5와 자기 평가 종합 표(○), 작성일·서명·확인자 줄. 비어 있는 칸은 빈칸(내려받기 전에 「입력 필요 n곳이 남았어요. 그대로 내려받을까요?」).

## 화면 (기타 › 다면평가, `web/menus/etc/multi*.js`)
- 위: 내 정보(학교·직위·성명·담당 학년 및 학급·담당 과목·담임 여부·담당 업무·보직교사 여부·평가 기간·근무 6개월 이하) — 이 기기에만.
- [정량평가] [정성평가] 두 쪽(누른 쪽 기억).
- 정량: 기준 양식 [넣기]/[지우기] + 지금 기준 이름, 묶음마다 항목 줄(이름·배점·입력: range는 숫자+단위, choice는 고르기, count는 횟수, 감점 있으면 감점 칸) → 바로 고른 지표·점수, 묶음 소계, 맨 위·아래 총점 「90 / 100점」. 항목마다 근거자료 칸·비고·증빙 안내(guide). [한글로 내려받기 ▾].
