# 학급 › 기초학력 캠프 — 설계 (2026-11-11)

선생님 요청: 기초학력(교과캠프) **출석부·관찰기록부·수업확인서**를 학급 탭에. 양식을 넣으면 그에 맞게 작성, 프롬프트로 만들기, 학생 출석 체크.
선생님 답: 학생 이름은 **이 기기에만 저장**(AI로는 학생A·학생B) · 출석 단위는 **캠프마다 고르기(교시마다/날마다)** · AI로 **일정·지도 내용, 관찰 및 지도 결과, 결과 보고서** · 자리 **학급 › 기초학력 캠프**.

참고 양식(선생님이 보낸 것, 저장소에 넣지 않음):
- 수업 확인서: 제목(「3-(1) 느린학습자 지원 중점학급 교과캠프 수업 확인서」), 지도교사, 결재란(계(담당자)·교감·교장), 표 `순 | 날짜 | 시간 | 교과 | 지도 내용 | 확인(서명)`, 끝 줄 「계 | 지도 시간: 총 ( n )시간」, 「※확인(서명)란은 지도 교사가 반드시 날인(사인)」.
- 학생 출석 및 관찰 기록부(교시형): 「※ 출석 : ○ , 결석 : /」「※ 출결 표시 및 계는 수기 작성」, 표 `순 | 일시(날짜) | 시간 | 학생1 | 학생2 | …`(날짜 칸은 그날 교시들을 묶음), 끝 줄 「계 | 학생별 출석 수」.
- 학생 출석부(날짜형): 표 `순 | 학년-반 | 이름 | 날짜1 | 날짜2 | … | 계`.
- 관찰 기록부: 표 `이름 | 학생1 | 학생2 | …` 아래 `관찰 및 지도 결과 | 학생별 글`(한 쪽에 학생 5명까지).
- 결과 보고서: 사업선택제 [서식 2](운영 목적·운영 내용·운영 성과, 2쪽 이내) / 이끎교사 [서식 1](필요성 및 목적·추진 내용·결과 및 결론·일반화 방안, 5쪽 이상).

## 공통 규칙
- 해요체·짧게. 저장·결재는 선생님이. 연수 메뉴·README·RELEASE_NOTES·버전 파일은 영역 작업에서 고치지 않음.
- **이름**: 캠프 학생 이름은 학년도별 키 `camp`(브라우저 저장소, `core/years.js` 규칙)에만. 백업 파일에는 들어감(선생님 동의). **AI로 보내는 글에는 이름 대신 학생A·학생B…**(캠프 안 차례), AI 답에 학생A가 있으면 그대로 둠(문서·보고서도 학생A로 — 보고서 예시도 「(학생A)」). 관찰 메모의 이름(캠프 학생 이름 그대로 쓴 것)은 보낼 때 학생A로 바꾸고, 그 밖의 이름 모양은 `core/chat-names.js maskPersons`로 가림.
- 지도교사 이름: 캠프 정보 칸(선생님 자신). AI로 보내지 않음.
- AI는 `core/ai.js`의 기존 업무(`plan` — 일정·보고서, `writing` — 관찰 글)만.
- 문서 내보내기: `core/doc-export.js`(한글·워드·PDF). 표는 단순 표(합친 칸 없음) — 같은 날짜는 첫 줄에만 적고 나머지 날짜 칸은 비움.

## 화면 (학급 › 기초학력 캠프, `web/menus/class/camp*.js`)
- 캠프 목록(이 학년도) + [새 캠프]. 캠프 하나: 이름(제목), 지도교사, 대상(예: 3학년), 출석 단위(교시마다/날마다), 교과(국어·수학…), 결재란 칸(기본 「계(담당자)·교감·교장」, 고칠 수 있음), 학생(학년·반·번호·이름).
- **수업 일정**: 줄마다 날짜·시작·끝·교과·지도 내용. [+ 줄], [한 날 여러 교시 더하기](날짜 + 시간표 묶음), [AI로 만들기](프롬프트 한 칸: 「1/8~1/23 평일, 9:00~12:40 하루 5교시(40분·쉬는 5분), 국어·수학, 3학년 2명, 아이스크림 홈런」 → 날짜·시간·교과·지도 내용 줄. 주말·공휴일(core/calendar)은 앱이 빼고, 지도 내용은 교과·차시에 맞게 AI가 씀. 기존 줄이 있으면 바꿀지 더할지 물음).
- **출석 체크**: 오늘(또는 고른 날)의 수업(교시마다면 그날 교시들, 날마다면 그날 한 줄) × 학생 표. 칸을 누르면 ○ → / → 빈칸. [모두 출석]. 학생별 출석 수·출석률. 날짜 고르기.
- **관찰 기록**: 학생별 메모 칸(짧게) + 「관찰 및 지도 결과」 칸. [AI로 쓰기]: 학생별 메모·출석 수·지도 내용 요약을 학생A로 보내 2~4문장(「~함.」「~임.」 꼴, 개조식 아님). 선생님이 고친 칸은 다시 쓰지 않음(덮을지 물음).
- **결과 보고서**: 보고서 꼴 고르기(사업선택제 결과 보고서 / 이끎교사 운영 보고서 / 학교 양식 글 머리 따르기), 프롬프트 칸(목적·성과 메모), [AI로 쓰기] → 제목·섹션별 글(학생은 학생A). 고칠 수 있는 칸, 내보내기.
- **문서 내보내기**: 수업 확인서 · 출석 및 관찰 기록부(교시형) / 출석부(날짜형) · 관찰 기록부 · 결과 보고서. 각각 [한글로 내려받기 ▾].
- **양식 넣기**(문서마다): 
  - `.hwpx` 학교 양식 → 그 양식의 표를 찾아 채움(아래 core). 제목·지도교사·「총 ( )시간」 글도 바꿈. 결재란은 그대로.
  - PDF·사진·`.hwp` → AI가 양식 모양(제목·표 칸 이름·안내 글)을 읽어 기본 양식을 그 모양으로(칸 이름·순서·제목) 바꿔 내보냄. 학생 이름이 보이는 양식 사진은 이름 칸을 가리지 않고 보내므로 「이름이 적힌 양식은 빈 양식으로 넣어 주세요」 안내.
  - 넣은 양식은 `core/form-store.js forms('camp')`에 저장(다른 메뉴 양식과 따로).
- 채팅: 「캠프 출석」「기초학력 캠프」「교과캠프」→ 이 탭(`web/core/chat-route.js`, `chat-knowledge.js`).

## 데이터 (`camp-model.js`, 순수 함수 + 저장)
```
camp = { id, name, teacher, target, unit: 'period'|'day', subjects: [], approval: ['계(담당자)','교감','교장'],
  students: [{ id, grade, cls, no, name }],
  sessions: [{ id, date:'YYYY-MM-DD', start:'09:00', end:'09:40', subject, content }],   // 날마다면 날짜당 한 줄
  att: { [sessionId]: { [studentId]: 'O'|'X' } },  // X = 결석(/), 없으면 안 씀
  memo: { [studentId]: '' }, obs: { [studentId]: '' }, obsEdited: { [studentId]: true },
  report: { kind, prompt, title, sections: [{ head, text }] }, forms: { confirm, attend, observe, report: formId|'' }, updatedAt }
```
- `attCount(camp, studentId)`, `hoursTotal(camp)`(수업 줄 수), `sessionsOn(camp, date)`, `aliasMap(camp)`(학생 → 학생A…), `toAlias(text, camp)`/`fromAlias`(안 씀 — 문서는 학생A 그대로), `expandDates(from, to, { weekdays, skipHolidays })`, `periodSlots('09:00', 5, 40, 5)`.
- 문서 모양(`camp-docs.js`): `confirmDoc(camp)`, `attendDoc(camp)`(unit에 따라 교시형/날짜형), `observeDoc(camp)`(5명씩 쪽), `reportDoc(camp)` → `core/doc-export.js` doc.

## 학교 한글 양식 표 채우기 (`web/core/hwpx-table.js`, 새 core)
- `readTables(u8) → { tables: [{ index, rows: [[cellText…]], rowCnt, colCnt }], texts: [문단 글] }`(합친 칸은 왼쪽 위 칸에만 글).
- `pickTable(tables, words)`: 머리 줄에 `words`(예: ['날짜','시간','교과','지도'])가 가장 많이 든 표.
- `fillTable(u8, { table, headRows, rows: string[][], footer?: { match: /계/, cells: string[] }, replace?: [[찾을 글, 바꿀 글]] }) → Uint8Array`: 머리 줄 다음 첫 데이터 줄을 본으로 복제해 `rows` 수만큼 채우고(칸 모양·테두리 그대로, rowAddr·rowCnt 다시 매김), 남는 빈 줄은 지우고, 끝 줄(계)을 찾아 채움. 본 줄에 합친 칸(rowSpan>1)이 있으면 그 칸은 풀어서 칸마다 씀. `replace`는 문단 글 바꾸기(「총 (   )시간」→「총 ( 35 )시간」, 「지도교사 :」 뒤 이름).
- 순수 XML 처리 + zip(기존 `hwpx-form.js`가 쓰는 zip 읽기·쓰기). 시험: `makeHwpx`로 만든 표, 손으로 만든 rowSpan 표, 줄 수가 모자라거나 남는 경우, 깨진 파일.

## 시험
- 단위: 모델(날짜 펼치기·교시 묶음·출석 수·학생A 바꾸기·이름이 AI 글에 없음), 문서 모양, hwpx-table.
- 화면(e2e): 캠프 만들기 → 학생 2명 → 일정 AI(가짜) → 출석 체크(○·/·빈칸, 모두 출석, 계) → 관찰 AI(프롬프트에 이름 없음) → 보고서 AI → 문서 내보내기 4종 → hwpx 양식 넣어 채우기 → 새로 고침 뒤 그대로.
