# 학급 탭 제대로 만들기 (2026-11-18)

선생님 요청: 「학급 메뉴도 구현해줘야 할 것 같아」 → 「네가 맡아서 알아서 고쳐줘. 지금 탭을 제대로 구현해줘」(새 탭이 아니라 지금 탭 4개를 제대로).
학급 탭 4개를 검토자 3명이 나눠 살펴 찾은 버그·모자란 점(모두 재현·코드로 확인)과, 고칠 때 정한 것(제 판단 — 선생님이 맡김). 학생 이름이 AI로 가는 것이 가장 먼저.

## A. 오늘 수업 · 진도표·시수 (class-model.js·today.js·progress.js·setup.js·class-import.js)

버그
1. **시간표를 고치면 지난날과 기록이 바뀜**(시간표 하나로 모든 날을 셈, 다른 교과 기록을 덮어씀) → 시간표에 판(`versions: [{ from, cells }]`)을 두고 그날 쓰던 판으로 셈.
   시간표 칸을 고칠 때 지난 기록이 있으면 한 번 물음: [오늘부터 바꾸기(지난 기록 그대로)](기본) / [처음부터 고치기(잘못 넣었음)]. 지난 칸은 기록된 교과를 보여 주고, 다른 교과 기록을 말없이 덮어쓰지 않음.
2. **「다음 차시」를 바꾸면 실시 시수가 바뀜** → 처음 실시 시수(`hours0`, 가져올 때 한 번)와 진도 자리(`offset`)를 나눔. 예전 자료는 `hours0 = offset`으로 옮김.
3. **공문 기한 띠: 오래 지난 공문이 오늘 기한을 밀어냄** → 「오늘」 화면 공문 카드와 같은 차례(오늘·가까운 것 먼저), 3개 + 「외 n건」.
4. **앞날도 체크되고 바로 시수에 셈** → 오늘 뒤 날짜는 체크 단추를 끄고 「앞날은 체크할 수 없어요」.
5. **반만 체크한 날은 「체크하지 않은 날」에 안 나옴** → 진도표 교과 칸이 남은 날도 「11/16(월) 2교시 남음」처럼.
6. **가져오기: 「2026학년도 3학년 국어 교육과정 연간지도계획」「국어과 …」「연간 지도 계획」을 잘못 읽음, 「2~3/4」 두 시간 줄을 버림** → 학년도·학년·끝 「과」를 빼고, 띄어 쓴 이름·교육과정 없는 제목도, 두 시간 줄은 한 시간씩.
7. **학사일정의 「재량휴업일」「개교기념일」「휴업일」은 수업이 있는 날로 셈** → 그 이름의 학사일정 날은 수업 없는 날(「방학식·개학식」은 수업 날, 방학은 설정 › 학교 정보의 방학으로).

모자란 점
8. **진도표가 없는 교과(영어·음악·미술·체육·도덕·창체)는 체크도 시수도 없음** → 그 교과도 [완료/일부 진행/못 함]을 누르고 진도표·시수 표에 「시수만」 줄(실시, 계획은 준비에서 적거나 비움). 준비에서 교과마다 「전담」(체크하지 않음)을 고를 수 있음.
9. **하루 한꺼번에·교체 수업이 없음** → [남은 칸 모두 완료]·[이 날 모두 못 함](학사일정이 있는 날은 띠에 바로), 교시마다 [교과 바꾸기](교체·보강 — 그날 기록에만).
10. **요약과 준비가 한 화면에 길게, 다음 차시를 줄 번호로 맞춤** → 시간표·진도표가 있으면 준비는 접어 두고 맨 위 [시간표·진도표 고치기]; 표의 진도 차이 옆 [진도표대로 맞추기], 다음 차시는 「단원 n/N차시」로 고름; 오늘 수업에서 고른 날짜는 학급 탭을 오가도 그대로.
11. **수업 메모가 없음** → 교시마다 짧은 메모(「활동 3 못 함, 다음 시간에」), 그 교과 다음 시간 줄에 「지난 시간: …」.
12. (여유가 있으면) 창체 영역(자·동·봉·진) 시수, 2학기 진도표로 바꿔도 연간 실시.

## B. 주간학습안내 (weekly.js, class-model.js 아래쪽 cellText·NOTE_ROWS·weeklyDoc·weekPeriods)

버그
1. **학생·교직원 이름이 가려지지 않고 AI로 감**(학사일정 글·이미 쓴 알림 칸) → 보내기 전에 makeRedactor로 가리고 답은 되돌림, 화면의 「AI로 가는 것」 안내도 고침.
2. **체크를 안 하면 다음 주 차시가 앞으로 안 감** → 주간학습안내의 앞으로 셈에서는 체크하지 않은 지난 칸을 진도표대로 한 것으로 봄(오늘 수업·시수는 그대로), 「체크하지 않은 날 n일」 알림.
3. **AI가 수업 없는 날에도 알림을 채움** → 수업 없는 날은 건너뜀.
4. **AI가 선생님이 고친 교과 칸을 안 봄** → 보낼 때 화면 칸(weekCell) 그대로.
5. **연간계획의 업무 일정(「교직원 연수 및 결과 보고」)이 학부모 안내의 학사일정 줄에** → 연간계획 일정은 빼고(학사일정·행사계획만).

모자란 점
6. **[다시 채우기]가 고친 칸을 말없이 다 지움, 고친 칸 표시 없음, 학사일정 줄은 자동으로 못 돌아감** → 고친 칸 수를 알려 주고 묻기, 자동 글과 같아진 칸은 고침에서 뺌, 고친 칸 표시, 학사일정 줄도 다시 채우기에.
7. **교과서 쪽수·비고를 안 씀** → 칸에 「(42~43쪽)」, 비고는 AI 알림의 참고로.
8. **내보내기 모양**: 교시 칸 폭·수업 없는 날은 그날 칸 모두에 까닭·맨 위에 학교 이름.
9. **한 주 전체 「알려 드립니다」 칸이 없음** → 화면·한글·복사에 자유 글 칸 하나.
10. **교시 수를 줄이면 숨은 칸이 내보내기에 남음** → 시간표 교시 수까지만.

## C. 기초학력 (camp*.js)

버그
1. **학생 이름(성 뺀 이름 + 「이에게서」「부터」「였음」…, 띄어 쓴 이름)이 AI로 감** → 프로그램 학생 이름마다 띄어쓰기를 빼고, 앞이 한글이 아닌 자리의 성 뺀 이름은 뒤에 무엇이 오든 가림(지나치게 가리는 것이 새는 것보다 낫다는 원칙).
2. **결과 보고서 [+ 칸]이 아무것도 안 함, 칸을 비우면 다음 칸 글이 엉뚱한 칸에** → 빈 칸도 저장(내보낼 때만 뺌), 칸마다 id, 칸이 없으면 고른 꼴의 글 머리로 채움.
3. **지도 시간이 출석 단위(날마다·교시마다)에 따라 달라짐** → 줄마다 교시 수(또는 시각으로 셈)를 더함.
4. **[지금 줄에 날짜 넣기]가 출석을 다른 날로 옮김** → 체크가 있는 줄의 날짜가 바뀌면 묻고, 체크를 비울지 고름.
5. **날마다인데 같은 날 줄이 여럿이면 단계와 출석 화면이 어긋남** → 날마다로 바꿀 때 같은 날 줄을 합치고, 출석 화면도 날마다면 하루 한 줄.
6. **일정 줄 ×는 그 줄 출석을 말없이 지움** → 체크가 있으면 묻기.
7. **결재란을 비울 수 없음** → 비운 것은 비운 대로(새 프로그램만 기본값).
8. **「도달하지 못한 학생」에서 온 학생(이름 없음)이 모두 「이름 없음」** → 「3-2 5번」처럼 번호로.

모자란 점
9. 빈 화면 단추 이름 「새 프로그램」 하나로.
10. 사진·스캔 계획 파일은 그림으로 AI에 감 → 「이름이 그대로 보일 수 있어요」 알림과 확인.
11. 날짜 없는 줄: 하루씩 화면에도 알림, 출석부 준비는 수업 일정으로 안내.
12. 문서 내보내기 단계에 문서마다 준비됨·할 일과 그 단계로 가는 단추, 빈 문서는 내보내기 전에 알림.

## 하지 않는 것

- 새 탭(학급 › 상담·자리 배치 등) — 선생님은 「지금 탭을 제대로」.
- 연수 메뉴(다른 선생님 보류).
