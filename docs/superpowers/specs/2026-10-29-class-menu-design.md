# 학급 메뉴 설계 (오늘 수업 · 진도표·시수 · 주간학습안내)

- 날짜: 2026-10-29
- 바탕: PRD 5.6 (원래는 화면 시안) → 선생님 결정으로 **실제로 동작하는 기능**으로 바꿈
- 결정 기록
  - 동작하는 기능으로 만든다 (2026-10-29 질의)
  - 진도표는 주차가 있는 것과 없는 것을 둘 다 받는다 (2026-10-29 질의)
  - 접근 A: 차시 목록을 정리해 저장하고 계산은 앱이 한다. AI는 진도표 읽기와 주간학습안내 문장에만 쓴다.

## 1. 누가, 무엇을

- 사용자: 초등 담임 한 명, 자기 반 하나.
- 전담 교과(영어·과학 전담 등)는 진도를 따지지 않는다. 진도표를 넣지 않은 교과는 시간표·주간학습안내에 이름만 보인다.
- 성공 기준
  - 시간표와 진도표를 한 번 넣어 두면, 매일 오늘 수업에서 체크만 해도 시수와 진도 차이가 저절로 나온다.
  - 금요일에 다음 주 주간학습안내를 몇 분 안에 한글 파일로 뽑는다.
  - AI 키가 없어도 시간표·진도표 직접 입력, 체크, 시수 계산, 주간학습안내 표와 한글 파일은 된다.

## 2. 처음 준비 (진도표·시수 탭 아래 「준비」)

1. **학급 이름**: 예) 「4학년 2반」. 주간학습안내 제목에 쓴다.
2. **시간표**: 월~금 × 1~6교시(4~7교시로 바꿀 수 있음). 칸마다 교과 이름을 쓴다(이미 넣은 교과 이름을 고를 수 있게 목록 제공). 빈 칸은 수업 없음.
3. **교과별 진도표**
   - [교과 추가] → 교과 이름 → 진도표 파일(한글·PDF·엑셀·CSV)을 올리거나 글을 붙여 넣기 → [AI로 차시 뽑기].
   - AI가 그 교과의 차시 목록을 뽑는다. 한 줄 = 1시간: 주차(없으면 빈칸), 단원, 차시 제목, 쪽수. 「3~4차시」처럼 두 시간짜리는 두 줄로 나눈다.
   - 결과는 표에서 고친다(줄 추가·삭제, 칸 고치기). AI 없이 표에 직접 써도 된다.
   - 방금 읽은 파일은 화면을 떠나기 전까지 기억해서, 같은 파일로 다음 교과를 바로 뽑을 수 있다(파일은 저장하지 않음).
4. **시작점**: 교과마다
   - 진도표 시작일: 주차 1이 시작하는 날(주차가 없으면 이 날부터 시간표대로 센다). 기본값은 오늘.
   - 다음에 할 차시: 지금까지 한 데까지. 학기 중간에 시작해도 된다.
5. **[예시로 채우기]**: 심사·시연용으로 지어낸 4학년 2학기 시간표와 교과 진도표(국어·수학은 주차 있음, 사회·과학은 주차 없음)를 채운다. 이미 자료가 있으면 「지금 자료를 지우고 예시로 바꿀까요?」를 묻는다.
6. 시연용 샘플 파일 `samples/진도표-예시.hwpx`(지어낸 주별 진도표)를 레포에 둔다.

## 3. 계산 규칙

### 3.1 수업이 있는 날과 시간
- 수업이 없는 날: 토·일, 공휴일(`core/calendar.js`의 표), 설정 › 학교 정보의 방학·재량휴업일.
- 수업 시간(slot) = 수업이 있는 날의 (교시, 그 칸의 교과).
- 학사일정(연간계획·행사 확정분)은 화면에 보여 주기만 하고 수업 시간을 빼지 않는다. 행사로 수업을 못 했으면 [못 함]을 누른다.

### 3.2 체크
| 버튼 | 시수 | 진도 |
|---|---|---|
| 완료 | +1 | +1 (다음 차시로) |
| 일부 진행 | +1 | 그대로 (다음 시간에 같은 차시) |
| 못 함 | 그대로 | 그대로 |

- 같은 버튼을 다시 누르면 체크가 지워진다.
- 기록은 날짜·교시마다 **그때의 교과 이름과 함께** 저장한다. 학기 중에 시간표를 바꿔도 지난 기록은 그대로다.

### 3.3 그 시간의 차시
- 교과의 차시 번호(0부터) = 시작 보정값 + 그 시간보다 앞선(날짜·교시 순) 그 교과의 「완료」 기록 수.
- 같은 날 국어가 두 시간이면, 앞 시간을 완료하면 뒤 시간은 다음 차시가 된다.
- 「다음에 할 차시」를 고치면 기록은 그대로 두고 시작 보정값을 맞춘다(보정값 = 고친 차시 − 1 − 지금까지 완료 기록 수).
- 차시 목록을 다 마치면 「진도표의 차시를 모두 마쳤어요」.

### 3.4 시수
- 계획 시수 = 그 교과의 차시 수.
- 실시 시수 = 시작 전에 한 차시 수(보정값, 0 아래면 0) + 「완료」·「일부 진행」 기록 수.
- 남은 시수 = 계획 − 실시 (0 아래면 0).

### 3.5 진도 차이 = 실제 끝낸 차시 수 − 지금까지 했어야 할 차시 수
- 「지금까지」 = 어제까지의 수업 시간 + 오늘 수업 시간 중 이미 체크한 것. (아침에 열어도 오늘 수업 때문에 뒤처져 보이지 않게)
- 주차가 있는 진도표(한 줄이라도 주차가 있으면):
  - n주차 = 시작일이 든 주의 월요일 + 7×(n−1)일부터 그 주 금요일까지.
  - 했어야 할 차시 = 지난주까지 주차의 차시 수 + min(이번 주 차시 수, 이번 주 월요일부터 「지금까지」의 그 교과 수업 시간 수).
- 주차가 없는 진도표: 했어야 할 차시 = 시작일부터 「지금까지」의 그 교과 수업 시간 수 (차시 수를 넘지 않음).
- 시작일 전이면 0, 화면에 「시작 전」.
- 표시: +2(앞섬), 0(맞음), −1(뒤처짐).

### 3.6 앞으로의 예상 (주간학습안내)
- 어제까지와, 오늘 이미 체크한 시간은 실제 기록대로 차시를 보인다.
- 그 뒤의 시간은 매시간 한 차시씩 나간다고 보고 지금의 다음 차시부터 이어서 채운다(보려는 주 앞에 남은 이번 주 시간도 센다).
- 체크하지 않은 지난 시간은 진도가 나가지 않은 것으로 본다.

## 4. 화면

### 4.1 오늘 수업
- 위: 날짜(「10월 29일 (목)」), [◀] [오늘] [▶], 날짜 고르기.
- 그날 학사일정이 있으면 날짜 아래에 칩으로 보여 준다.
- 수업이 없는 날: 이유(「토요일」, 「공휴일(개천절)」, 「겨울방학」)만 보여 준다.
- 교시마다 한 줄: 「1교시 · 국어 · 3. 바르게 대화해요 · 5/12차시 · 차시 제목 · 34~37쪽」 + [완료] [일부 진행] [못 함] (누른 것은 눌린 모양).
  - 진도표 없는 교과: 「진도표 없음」, 버튼 없음.
- 체크하지 않은 날: 오늘 앞의 수업일 10일 안에서 진도표 있는 교과의 수업이 있는데 체크가 하나도 없는 날을 「체크하지 않은 날: 10/27(화) 10/28(수)」로 보여 주고, 누르면 그날로 간다.
- 시간표가 없으면: 「먼저 진도표·시수 › 준비에서 시간표를 넣어 주세요」 + [준비로 가기] [예시로 채우기].

### 4.2 진도표·시수
- 요약 표: 교과 | 계획 | 실시 | 남은 | 진도 차이 | 다음 차시 | 기준(진도표 주차 / 시간표). 실시/계획 막대.
- 시간표에 있지만 진도표가 없는 교과는 요약에 넣지 않는다. 진도표는 있는데 시간표에 없는 교과는 「시간표에 없어요」를 보인다.
- 아래 「준비」(2장): 학급 이름, 시간표, 교과 목록(이름·시작일·다음 차시·차시 수·[진도표 고치기]·[삭제]), [교과 추가], [예시로 채우기].
- 교과 삭제는 확인 창을 거친다. 지난 기록은 지우지 않는다(같은 이름으로 다시 넣으면 다시 이어짐).

### 4.3 주간학습안내
- 위: 주 고르기 「11월 2일(월) ~ 11월 6일(금)」 [◀] [▶]. 기본은 목요일부터 주말까지는 다음 주, 그 밖에는 이번 주.
- 제목: 「{학급 이름} 주간학습안내」 (고칠 수 있음).
- 표: 줄 = 교시, 칸 = 월~금. 칸마다 교과와 차시 제목(3.6). 진도표 없는 교과는 교과 이름만. 수업 없는 날은 그 열에 이유. 칸은 고칠 수 있고, [다시 채우기]로 고친 것을 지운다.
- 표 아래: 요일별 학사일정 줄.
- 준비물·알림 사항: 글 칸 두 개. [AI로 쓰기]가 그 주의 차시와 학사일정을 보고 초안을 쓴다(학부모가 읽기 쉬운 말, 학생 이름 없음). 직접 써도 된다.
- 내보내기: [한글 파일](.hwpx), [인쇄](인쇄 창에서 PDF로 저장 가능, 안내 시트만 인쇄), [복사](글).
- 주마다 고친 칸·제목·준비물·알림 사항을 저장한다.

## 5. AI

- 차시 뽑기: 프롬프트 머리 `[진도표 읽기]`. 넣는 것: 교과 이름, 파일 글(60,000자까지, 넘으면 앞부분만 쓰고 알림). 받는 JSON: `{ "lessons": [{ "week": 9 | null, "unit": "3. 분수", "title": "분모가 같은 분수의 덧셈", "pages": "48~49" }] }`. 규칙: 그 교과만, 한 줄 = 1시간, 진도표 순서대로, 주차 칸이 없으면 null, 지어내지 않기.
- 주간학습안내 문장: 프롬프트 머리 `[주간학습안내]`. 넣는 것: 주 날짜, 요일별 교시·교과·단원·차시 제목, 학사일정. 받는 JSON: `{ "prep": "…", "notice": "…" }`.
- 공통: `core/ai.js`의 `generateJSON`(한 번 다시 묻기). AI가 끝났을 때 사용자가 다른 교과·다른 주로 옮겨 갔어도, 결과는 시작한 교과·주에 들어간다.

## 6. 저장 (`ssam:` 아래)

| 키 | 내용 |
|---|---|
| `class:info` | `{ name }` 학급 이름 |
| `class:timetable` | `{ periods: 4~7, cells: [월..금][교시] 교과 이름 }` |
| `class:subjects` | `[{ id, name, start, offset, lessons: [{ week, unit, title, pages }] }]` |
| `class:log` | `{ 'YYYY-MM-DD': { '<교시>': { subject, status: 'done' | 'part' | 'skip' } } }` |
| `class:weekly:<월요일 날짜>` | `{ title, cells: { '<요일>-<교시>': 글 }, prep, notice }` |

- 읽을 때 모양이 틀린 값은 버리고 기본값을 쓴다(화면이 깨지지 않게).
- 저장에 실패하면 「저장 공간이 모자라 저장하지 못했어요」 알림.

## 7. 오류와 예외

- AI 키 없음: 차시 뽑기·문장 쓰기 버튼을 누르면 「설정 › AI에서 키를 넣어 주세요」. 직접 입력은 그대로 된다.
- AI가 차시를 0개 돌려줌: 「이 교과의 차시를 찾지 못했어요. 교과 이름이 파일에 적힌 이름과 같은지 확인해 주세요.」
- 파일을 못 읽음: `core/files.js`의 안내 문구.
- 진도표 시작일이 빈 값·잘못된 값이면 오늘로 본다.
- 시간표 교과 이름과 진도표 교과 이름은 앞뒤 공백을 빼고 같으면 같은 교과로 본다.
- 좁은 화면: 시간표·주간학습안내 표는 표 안에서만 가로로 밀리고 쪽 전체에는 가로 스크롤이 생기지 않는다.

## 9. 시험

- Node(`tests/unit/class-model.test.mjs`): 수업 있는 날(주말·공휴일·방학), 수업 시간 목록, 완료·일부 진행·못 함과 같은 교과 두 시간의 차시 배정, 다음 차시 고치기(보정값), 계획·실시·남은 시수, 진도 차이 두 방식(오늘 체크 전·후 포함, 시작일 전), 다음 주 예상, 체크하지 않은 날, AI 차시 결과 정규화, 망가진 저장값.
- Playwright(`tests/e2e/class.mjs` 등, 가짜 AI·고정 시계): 예시로 채우기 → 오늘 수업 체크 → 진도표·시수 숫자 → 주간학습안내 AI 쓰기 → 한글 파일 내려받기. 진도표 파일 AI 뽑기 → 표 고치기. 시간표 없을 때 안내. AI가 도는 동안 다른 교과·주로 옮겨도 섞이지 않음. 좁은 화면 가로 스크롤 없음.
- 사람 확인: 주간학습안내 .hwpx를 한글에서 열기, Windows 앱에서 [인쇄] → PDF 저장.

## 10. 범위 밖

- 학기마다 다른 시간표를 따로 저장하기. 시간표는 하나만 두고, 바꾸면 진도 차이 계산(지난날 포함)과 예상도 새 시간표로 한다. 지난 체크 기록(날짜·교시·교과)은 그대로다.
- 학사일정을 진도표에 자동 반영(PRD 3.3, 대회 이후).
- 교과 시수 법정 기준과의 비교, 학년 전체 진도 공유.
