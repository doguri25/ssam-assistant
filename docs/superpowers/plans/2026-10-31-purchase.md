# 쌤비서 계획 2 · 품의와 한글 파일 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 품의 메뉴(PRD 5.2 P-1~P-9, P-10은 들어오는 함수만)를 동작하게 만들고, 연간·행사계획도 함께 쓸 `.hwpx` 쓰기(`core/hwpx.js`)와 견적서 읽기(엑셀·CSV 직접, 사진·PDF는 AI)를 갖춘 0.2.0을 낸다.

**Architecture:** 계산·점검·표 읽기·zip·hwpx는 DOM 없는 ES 모듈로 써서 Node `node --test`로 시험한다. 화면은 `menus/purchase/`의 모듈이 계획 1의 `onEnter`·`core/store.js`·`core/ai.js`를 써서 그린다. 기존 앱의 PDF·사진 읽기와 hwpx 파서는 `window.SSAM.files`로 꺼내 쓴다(옮기지 않음).

**Tech Stack:** 계획 1과 같음. 새 라이브러리 없음(압축 풀기는 `DecompressionStream('deflate-raw')`, zip 쓰기는 무압축).

**Spec:** `docs/PRD.md` (5.2 품의, 6.2 AI 공통 규칙, 7 저장, 8 보안, 9 기술 구조, 11 시험). 계획 1: `docs/superpowers/plans/2026-10-29-foundation.md`와 그 ledger의 `Ruling:` 줄.

## Global Constraints
- 계획 1의 Global Constraints를 모두 따른다.
- 금액은 원 단위 정수. 화면은 `toLocaleString('ko-KR')`(예: 12,000), 복사하는 표(TSV)는 쉼표 없는 숫자.
- 품의 종류 id·이름: `goods` 물품 구입 · `lecturer` 강사 수당 · `event` 행사 운영 · `meeting` 협의회. 기본은 `goods`.
- 저장 키: `ssam:purchase:current`(쓰는 중인 품의), `ssam:purchase:templates`, `ssam:purchase:recent`(최근 20개, 새것이 앞). 견적서 파일·사진은 저장하지 않는다.
- 주민번호·계좌번호 입력 칸은 어느 품의 종류에도 만들지 않는다(P-7).
- 계약 기준 금액은 `getPurchaseLimit()`(계획 1 `core/settings.js`)에서 읽는다.
- 파일 고르기 `<input type="file">`은 문서에 붙여 둔다(떼어 두면 Windows 파일 창이 열린 동안 사라짐 — 평어 만들기 1.7.2 버그).
- 문구는 PRD에 적힌 그대로 쓴다: 「견적서 글자를 읽지 못했어요. 직접 입력해 주세요」, 「개인정보는 넣지 말아 주세요」, 「예산 과목 · 행정실 확인 필요」, 「별도 계약 절차 확인 필요」, 「품목 금액의 합과 총액이 같아요」, 「주민번호·계좌번호가 들어 있지 않아요」, 「AI 답을 읽지 못했어요」.

## Review Focus
1. **금액 칸에 쉼표·「원」·공백이 섞인 값(「12,000원」), 소수 수량(2.5), 빈 품목 줄**: 바르게 계산하고 빈 줄은 무시한다. → Task 1 시험.
2. **엑셀 견적서의 머리줄이 몇 줄 아래에 있고, 합계·소계·빈 줄이 섞이고, 단가 없이 금액만 있음**: 품목 줄만 뽑고 단가는 금액÷수량. → Task 3 시험.
3. **엑셀에서 저장한 CSV(EUC-KR)**: 글자가 깨지지 않는다. → Task 3 시험.
4. **AI가 JSON 대신 코드 블록·설명이 섞인 답을 줌**: 코드 블록은 벗겨 읽고, 못 읽으면 한 번 다시 묻고, 그래도 안 되면 「AI 답을 읽지 못했어요」 — 입력은 그대로. → Task 4 시험.
5. **망가진 템플릿·최근 작성 저장 값(JSON 아님, 배열 아님, 칸 빠짐)**: 화면이 깨지지 않고 읽을 수 있는 것만 보인다. → Task 6 시험.
