# 「쌤」 채팅 마주온 톡톡 안내 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 「쌤」 채팅의 규정 질문(복무·수당·여비·민원·정책 …)에 AI 없이 마주온 톡톡 안내를 답 위에 붙이고, AI는 금액·날짜·조항을 지어내지 않게 한다.

**Architecture:** 규정 질문 알아보기는 `chat-route.js`의 순수 함수 `policyAsk(text)`(Node 시험). `chat.js`의 도우미 길(`assist` — AI·AI 없는 길 공통 입구)에서 답보다 먼저 `TOKTOK_NOTE` 한 줄. 채팅 AI 공통 안내(`assistGuide`)에 규칙 한 줄, 안내 찾기(`chat-knowledge.js`)에 항목.

**Tech Stack:** 빌드 없는 ES 모듈, `node --test`, Playwright e2e(`tests/e2e/helpers.mjs`).

**Spec:** `docs/superpowers/specs/2026-11-18-toktok-design.md`

## Global Constraints

- 안내 글(그대로): `교육청 규정은 **마주온 톡톡**이 정확해요. 마주온(ai.cne.go.kr) 로그인 → 첫 화면 맨 아래 「마주온 톡톡」에서 물어보세요.`
- 쌤비서 기능 질문·명령에는 붙이지 않음. 선생님께 보이는 글은 한국어, 해요체.

## Review Focus

- 「강사 수당 품의 어떻게 해?」(앱 기능 + 수당) → 안내 없음.
- 「출장비 품의 써 줘」(명령) → 안내 없음(규칙으로 품의 시작).
- 「연수 학점 몇 점 필요해?」 — 「연수」는 메뉴 이름이지만 규정 질문 → 안내 있음(앱 낱말에서 「연수」는 빼고 「연수 메뉴·연수 탭」만).
- AI가 없을 때(안내 찾기 길)도 안내가 먼저 보임.
- 긴 여러 줄 글(넣을 내용)에 규정 낱말이 섞여도 안내 없음(`isQuestion`이 거짓).

**Files:**

- Modify: `web/core/chat.js` (`assist` 첫 줄)
- Modify: `web/core/chat-assist.js` (`assistGuide` 답하는 규칙 한 줄)
- Modify: `web/core/chat-knowledge.js` (항목 `toktok`), `README.md` (「쌤」 채팅 줄 한 문장)

**Interfaces:**
- Produces: `policyAsk(text: string) => boolean`, `TOKTOK_NOTE: string` (chat-route.js)

- [ ] **Step 1: 실패하는 단위 시험** — `policyAsk`가 참: 「육아시간 하루 몇 시간까지 쓸 수 있어?」「출장비 얼마 받아?」「병가 쓰면 진단서 필요해?」「학부모 민원 어떻게 처리해야 해?」「연수 학점 몇 점 필요해?」「맞춤형 복지 포인트 언제까지 써야 돼?」. 거짓: 「강사 수당 품의 어떻게 해?」「품의 사유는 어떻게 써?」「출장비 품의 써 줘」「가정통신문 어떻게 써?」「오늘 할 일 뭐야?」, 여러 줄 글. `assistGuide()`에 「금액·날짜·조항」 규칙, `guideText()`에 「마주온 톡톡」, `TOKTOK_NOTE`가 위 글과 같음.
- [ ] **Step 2: 돌려 실패 확인** — `node --test tests/unit/fix1118-toktok.test.mjs` → `policyAsk` 없음으로 실패.
