# 사업별 예산 집행 현황 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 품의 › 예산 탭(사업마다 예산·집행·예정·남음), 품의마다 사업 고르기·남은 예산, [에듀파인에 올렸어요]로 집행, 직접 더한 줄, 마감 알림, 인수인계서 장부.

**Architecture:** 규칙·저장은 화면 없는 `web/menus/purchase/budget-model.js`(Node 시험). 탭 화면은 `budget.js`. 새 품의 화면(`purchase.js`)은 사업 칸·올림 단추·장부 덮어쓰기만 부름. 알림은 `core/brief-data.js gather` → `core/briefing.js briefing({ budgets })`.
지난 학년도 알림은 학년도와 상관없이 남는 요약 키 `budget:alerts`(GLOBAL)로.

**Tech Stack:** 빌드 없는 ES 모듈, `node --test`, Playwright e2e.

**Spec:** `docs/superpowers/specs/2026-11-18-budget-design.md`

## Global Constraints

- 학년도 저장 키: `budget:projects`, `budget:ledger`. 학년도와 상관없는 키: `budget:alerts`(years.js GLOBAL에 더함).
- 집행 = `posted`인 줄(직접 더한 줄은 늘 집행). 예정 = 올리지 않은 품의 줄. 남음 = 예산 − 집행 − 예정.
- 올림 표시 때 금액을 굳힘(`amount` 그대로, 그 뒤 품목이 바뀌면 `now`로 알림만).
- 마감 기본값 = 학년도 다음 해 2월 말일. 알림: 마감까지 0~30일 + (예산 − 집행) > 0.
- AI로 보내는 것 없음. 선생님께 보이는 글은 한국어 해요체. 시험 예시는 지어낸 것.

## Review Focus

- 같은 품의 초안을 여러 번 다시 맞춰도 장부 줄은 하나.
- 「최근 작성」에서 지운 예정 줄은 사라지고 집행 줄은 남음, 20개에서 밀려난 줄도 예산 탭에서 올림·사업 바꾸기·빼기.
- 사업을 지우면 그 품의들은 「사업 없음」으로(장부 줄은 남음).
- 예산이 비었거나 0인 사업(남음 음수 아님 처리), 금액 0인 품의.
- 학년도를 바꾼 뒤에도 지난 학년도 사업 알림(`(2026학년도)`).
