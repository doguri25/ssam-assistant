# 수준별 기준표(루브릭) 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 평가계획 평가요소마다 「채점 요소 × 수준」 기준표를 AI로 만들고 고쳐 저장하며, 과목·평가요소가 같을 때만 평가지 채점과 평어에 쓴다.

**Architecture:** 순수 규칙은 `web/menus/evaluate/rubric-model.js`(Node 시험), 시트 화면은 `web/menus/evaluate/rubric.js`가 `window.SSAM.rubric`으로 내보낸다.
레거시 `evaluate.js`(classic script)는 `RB()`(`window.SSAM.rubric` 또는 null)로만 부르고, 없으면 지금 동작 그대로.
평가지 채점은 시작할 때 기준표를 채점 기록에 복사(`GR.rubric`)해 그 사본만 쓴다.

**Tech Stack:** 빌드 없는 ES 모듈, `core/ai.js` `generateJSON`(업무 `plan`), `core/store.js` get/set(`ssam:` 키·학년도마다), `core/doc-export.js`, `core/redact.js`, node:test, Playwright e2e(`tests/e2e/helpers.mjs` 가짜 AI).

**Spec:** `docs/superpowers/specs/2026-11-16-rubric-design.md` (선생님 확인 2026-11-16: 「직접 입력」 채점에는 기준표를 쓰지 않음)

## Global Constraints

- 열쇠: `bare(subject) + '|' + bare(elem)`; `bare`는 evaluate.js `normKey`와 같은 규칙(`/[\s.,·ㆍ'"‘’“”~()!?;:\-]/g` 지움). 둘 중 하나라도 비면 열쇠 없음(기준표 안 붙음). 평가요소 이름은 `u.elem || u.unit`.
- 저장 키 `ssam:rubrics` = `{ v: 1, items: { [key]: rubric } }`(core/store.js `get/set('rubrics')`, `years.js` GLOBAL에 넣지 않음).
- rubric = `{ v: 1, subject, elem, unit, std, levels, rows: [{ id, name, points, cells: { [lv]: { text, pts } } }], task, at }`.
- 수준: `crit.top` 있으면 `['top','high','mid','low']`, 없으면 `['high','mid','low']`. 이름 최상·상·중·하. `none`은 「안 함」 0점(채점 답에만).
- 기본 배점: 요소 배점 = 100 ÷ 요소 수(나머지는 앞 요소부터 1점씩). 수준 점수 = round(배점 × 비율): 3단계 1 / 0.7 / 0.4, 4단계 1 / 0.8 / 0.6 / 0.4.
- 요소 2~5개(기본 3), 칸 글 200자, 과제 설명 1,000자, 요소 이름 40자.
- 채점: 기준 점수 = round(고른 수준 점수 합 ÷ 배점 합 × 100); 최종 점수는 기준 점수 −4~+4(0~100)로 자름. 배점 합이 0이거나 남은 요소가 없으면 자르지 않음.
- 화면 말투 해요체, 지어낸 이름만(김하늘·이바다·한가람·박솔빛·새싹초등학교), `web/menus/class/**`·연수 화면 안 고침, 390·360px에서 가로로 넘치지 않음.
- 「AI로 가는 것」 글(시트): 「학년·과목·단원·성취기준·평가요소·평가기준과 과제 설명을 보내요. 학생 자료는 보내지 않아요. 교직원 이름·연락처는 가려 보내요.」

## Review Focus

- AI가 수준을 키 대신 글로 줌(「상」「잘함」「안 함」) → `normRb`가 이름으로도 받음 (Task 1 시험).
- 배점·점수가 모두 0이거나 비어 있는 기준표 → 기준 점수 NaN 없이 자르지 않음 (Task 1 시험).
- 평가계획을 새로 넣어도(단원 id가 바뀜) 과목·평가요소가 같으면 같은 기준표, 「수학 」처럼 띄어쓰기만 달라도 같음 (Task 1 시험).
- 3↔4단계를 바꾸면 없어진 수준 칸은 빠지고 새 수준 칸은 빈 글, 선생님이 고친 점수는 그대로 (Task 1 시험).
- 채점 중(잠금)·지난 채점 기록에서 연 기준표는 보기만 — 고치기·만들기 단추 없음 (Task 4 e2e).
